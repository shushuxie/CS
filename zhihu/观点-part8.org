  - 一句话概括：作者认为中国校服丑的根子不在审美或成本，而在于它被设计成掩盖第二性征、压制青春期性冲动以防早恋，背后是社会对「升学才是出路」的焦虑，本质是意识形态问题。
  【方法/论点要点】
  - 对比立论：外国（英/美/韩/日）校服以体现青春期的青春特征为设计目的，而~中国校服的一个最大特点就是要掩盖青春特征……是以掩盖第二性征为目的的~，无论身材如何一律掩盖，目的是压制性特征与性冲动、防止早恋。
  - 社会氛围成因（日本）：日本家长鼓励中学生恋爱甚至上床、结婚（男性合法婚龄 18、女性 16），有调查称高达 37% 的日本家长接受孩子小学阶段谈恋爱；因日本男性工作后多从一而终、接触异性机会窄，中学阶段没找到伴侣则余生单身概率很高，中学生恋爱转为结婚比例高达 70%——所以日本女中学生校服设计得「带感」、冬天也光腿。
  - 欧美成因：合法结婚年龄早、社会保障完善，不必把升大学当唯一出路，中学生恋爱稀松平常，父亲甚至会手把手教性知识。
  - 真正根源：~表面看是学校的审美不行，但真实的情况，是中国的学校对于学生考分的重视程度甚于任何一个发达国家~（中国中学生也确实很厉害）；而重视考分源于整个社会「升学才是出路」的压力。
  - 反例：到有钱人的私立学校看看，那里的校服绝不会比发达国家差。
  - 驳成本论：不排除有学校拿回扣，但即使用不高于宽大运动服的成本也能做出漂亮校服；~漂亮的校服的成本不一定比丑的校服高~，本质上这是意识形态的问题，不是成本问题。

* 小学的成绩有很大的欺骗性，到了初中就会有很多的学生掉队，是真的吗？  :观点:教育:成长:心理:
  :PROPERTIES:
  :链接:  https://www.zhihu.com/question/433616847/answer/1670357512
  :作者:  老钱
  :原文:  [[file:原文/2026-10-19-小学的成绩有很大的欺骗性到了初中就会有很多的学生掉队是真的吗-1670357512.org][本地原文]]

  :END:
  - 本地原文：[[file:原文/2026-10-19-小学的成绩有很大的欺骗性到了初中就会有很多的学生掉队是真的吗-1670357512.org][打开本地归档]]
  - 一句话概括：回答认为小学成绩的欺骗性不在成绩本身，而在于有些取得成绩的方法不具可持续性；真正影响孩子前途的是学习带给他们的感受，安全感、归属感、尊重、专注力、见识广度这些「地基」比抢跑更重要。
  【方法/论点要点】
  - 引子（作者注明这只是引子、不是论据）：清北学生的来源高中有明显的集中度，初中集中度不那么明显，小学已没什么规律；很多清北学生出身不知名的乡村小学。小学阶段学生几乎没有自学能力、家庭教育乡村小学完败，成绩可能有很大差距，但不妨碍他们最后一起走进清北。
  - 核心论点：小学的成绩对将来的影响其实没想象中那么大，~真正影响孩子前途的，是学习带给他们的感受~。成绩不好还不足以决定命运，但如果成绩不好带来太多负面感受、导致厌倦甚至痛恨学习，影响将非常巨大。
  - 家长误区：很多人混淆了成绩和感受，家长更是用自己的感受代替孩子的感受——孩子成绩不好父母感受糟糕，就认为孩子感受也糟糕，认为必须快速把成绩提上去才能挽救孩子，于是各种鸡娃。可是越逼孩子感受越差、越不想学，陷入恶性循环，甚至亲子关系破裂、摧毁自信、失去安全感。相比成绩，小朋友更在乎家长的接纳和认可。
  - 分期差异：孩子的身体、智力、心理发育都有早晚，早期出现差异很正常；越是成绩不好的孩子越要关心心理感受，这是损害控制，只要还身心健康、不抵触学习，就还有逆袭的机会。
  - 可持续性：~所谓小学成绩的欺骗性，不是成绩本身有欺骗性，而是有些取得成绩的方法不具备可持续性，时间久了自然原形毕露。~ 一方面父母主导下的努力，很可能随青春期自我意识萌芽而土崩瓦解；另一方面小学就把所有时间精力投入学习，到初中科目数量难度大增时已加无可加，而自信全来自成绩，一旦下降就受打击、陷入恶性循环。另一些孩子小学成绩不突出，但有充足娱乐时间、学习时间上有潜力可挖、心态更从容，成绩可能逆势而上。
  - 重点校为何看重特长：~其实他们在乎的不是你会不会拉小提琴，而是要看看你的成绩是发了几分力的结果。~ 能报重点学校的成绩都优秀，差一两分能力上没区别，但能同时分出精力培养几项特长的差别就大了；学校看中的是特长背后体现的学习主动性和学习潜力。（举例：本地初中特色班大市招生，报名基本条件成绩全优，经多轮笔试面试最后只录取一百多人；开学统计一个班 40 人、坚持两年以上达一定水平的特长共 140 多项，平均一人超过 3 项。）
  - 马拉松比喻：一个普通人跑马拉松一起跑就拿出百米冲刺速度，可以领先专业运动员，但坚持不到终点；小学是教育长跑的起步阶段，全力以赴虽领先却透支体力，容易倒在半路。跑不过「刘翔」没关系，就享受奔跑的快乐，不求碾压别人，只求战胜自己。
  - 本质：~小学成绩的欺骗性，本质是家长在自己骗自己~——把抢跑的优势当成天赋的优势，高估孩子能力、制定超出身心承受能力的训练计划、以高压手段强制实施，最后把孩子练废。但也要避免另一种极端：迷信欺骗性、以为啥也不干到了中学就自动翻盘，是白日做梦。
  - 翻盘案例的共同点：~当别人已经开始盖房子的时候，他们在往下挖地基。~ 一栋房子最终能达到的高度，不是看你砌墙的速度，而是看你地基的深度和广度。
  - 什么是地基、怎么挖（按马斯洛需求理论）：父母望子成龙属第五层自我实现，必须先满足下层——生理的需要、安全的需要、归属与爱的需要、尊重的需要。经常吼孩子甚至打骂，何来安全感；整天说「考不上高中这辈子就完了」，何来安全感；因成绩不好就长吁短叹、一副你对不起我给我丢人的样子，孩子感受不到爱和归属；把孩子当私有物品、凡事父母安排、当机器人，孩子感受不到尊重。~人因自尊而自重，因自重而自强，因自强而自律。没有自尊的孩子，很难学会自律。~
  - 生理基础=专注力：低年级儿童成绩的差异绝大部分来自专注力的差距，所以别急着背唐诗学算术，先把孩子的专注力保护好。是「保护」而非「培养」——专注力常被家长破坏（孩子玩时被反复打断：该喝水了、该吃东西了、这个不能碰那个不可以），注意力不断被分散，同时被破坏的还有好奇心。孩子专注力天生有差距是客观事实，先接受再寻求改变，不要把注意力问题错误归结为态度问题、上纲上线打击人格自尊。
  - 专注力与兴趣相关：学习不专注的孩子可能打游戏就很专注，因为喜欢；所以要想法让孩子喜欢上学习，这就是培养兴趣和快乐学习。非把上学弄得像上刑，就别指望孩子喜欢、专注。
  - 基础除深度还需广度：金字塔的高度和底座广度密切相关，不要只盯着语数外，多带孩子出去走走看看，见识多了、体验多了才能找到方向，别等填高考志愿时才想「这辈子到底该干啥」。
  - 培养 vs 挖掘兴趣：~"培养"学习兴趣很难，但"挖掘"学习兴趣就要容易多了。培养，是以父母为主，无中生有。挖掘，是以孩子为主，因势利导。~ 这也是「如你所愿」还是「如他所是」的区别。

  - 一句话概括：回答从新加坡人用英语表达却干巴巴切入，论证语言与文化相辅相成——每种语言都承载着特定的敏感点，只会普通话或强行换用另一语言会同时失去两边精细的部分，方言与普通话是互补关系。
  【方法/论点要点】
  - 引子：看新加坡人写的东西，~单句看都写得挺好，全文看就干巴巴的，甚至狗屁不通~。以李光耀之女李玮玲的《我为什么选择单身?》为例，逐段看能看懂、信息量挺丰富，但全文很散、不知道想表达啥，故事没为主旨服务。李玮玲作为博士词汇量不大，基本没超出四级词汇；李光耀（母语英语、剑桥毕业、任新加坡总理 30 年）的书六级词汇量基本能看懂，而野生的西方人写的《How Google Works》词汇量大很多、看起来很吃力。
  - 原因：新加坡人又会说英语又会说中文，结果是两方面都不讨巧——就算英语很精通，文化内核仍是中华文明，用英文强行表达必然失去很多灵魂；在英语文化那边也没有盎格鲁撒克逊的灵魂。李光耀也提到过，读英校只会说英语的新加坡人比说华语的新加坡人冷漠很多。~文化和语言是互相成就相辅相成的，谁离开谁都走不长远。~
  - 核心理论：不同语言之间能完全共通翻译的部分其实很少，仅限一些基础词汇，更大部分是每种文化特殊的敏感点。
    - 颜色例：红黄蓝绿橙紫黑白八种基础颜色可等价翻译成 red/yellow/blue/orange/purple/black/white；但中国人对「水墨」敏感而有「墨绿」，对红枣熟悉而有「枣红」，无法等价翻译；英文对「铬（chrome）」这种金属敏感，水龙头、刀叉乃至镜子的颜色都叫 chrome 色，中文里大多只叫银色（silver 与 chrome 还是有差别的）。
    - 亮度例：中文对颜色的光泽度（glossiness）和亮度（brightness）不敏感，国外同事希望产品「更 bright」被理解成「更亮一点」，结果做成闪闪发光，其实只是想把颜色调浅；真要闪闪发光，老外会说更 glossy 一点。
  - 结论：~如果一个民族强行用另外一种语言作为日常沟通用语，则只会保留中间部分，而两边各自精细部分的词汇，将会失去。~
  - 词汇是文化作用的结果：一种文化越在意什么，都会在语言上体现。
    - 爱斯基摩人很在意雪，有几十个词形容不同的雪，对雪的感受更细腻。
    - 西方对狗敏感：canine（犬，学名）、dog（狗通称）、puppy（小狗）、hound（猎狗）、terrier（一种很活泼的小狗），看到狗一定会先区分再选词，如 Look at that puppy；对牛也敏感：bull（公牛）、cow（母牛）、buffalo（水牛）；对猫不敏感，首先想到 cat。
    - 中文对量词敏感：一台电脑、一辆车、一张桌子、一头牛、一只鸡、一粒米、一朵花、一条绳子、一件衣服、一根棍子、一支笔、一个人、一条女（粤语）、一旧云/一旧水（粤语）；量词体现事物的外形属性，听到「一条……」就能大概预判后面是什么。英语略过量词，对事物的观察没那么细腻。看到不同的水会想到一汪水、一滩水、一湾水、一洼水，英语则统一 Look at that water。
    - 新加坡人思维仍在中华文化里，讲英语习惯说 Look at that dog、第一反应不细分，所以英语词汇量低很多；反过来讲中文时量词完全弱化，统一用「个」——一个手机、一个电脑、一个桌子、一个笔、一个车、一个棍子、一个衣服。
    - 亲戚称谓例：中国严格区分爷爷奶奶和外公外婆，父亲一方的叔叔伯伯姑姑和母亲一方的姨妈舅舅也不一样，长幼也严格区分哥哥弟弟、姐姐妹妹；西方对这些不敏感，都叫 grandparents、uncle、aunt、brother、sister，导致英译中时不知把 grandpa 翻成爷爷还是外公。
  - 文化产品的例证：新加坡和香港人口规模差不多，香港文化影响力大，但新加坡从未诞生过知名的消费品牌，也没有有影响力的书籍、电影、综艺节目，最擅长的是作为中西方沟通的桥梁和西方世界的高级打工仔——处在两种语言中间，两边精细的部分都失去。
  - 普通话 vs 方言：普通话及书面用语长期作为官方语言，擅长逻辑、科学表达——很多方言里其实没有「因为」「所以」「虽然」「难道」「并且」（作者奶奶就永远不会用这些词，要表达就绕圈子）；进入现代社会后所有现代文明词汇也先进入普通话（科技、法律、医学），用方言很难表达。但普通话的欠缺是它对日常生活的描述，因为主要功能还是官方宣传和教育。
  - 方言擅长人文方面表达：旧时代老百姓接触不到上层，只能把精力放在生活和社会关系上——形容人的词汇特别多、形容心情和粗口特别多、做人做事的俗语特别多。如粤语「心思思」「心挂挂」「巴闭」「牙擦擦」，湖南话「哈苞」「带笼子」「稀下的」，普通话无法完全对应。
  - 方言承载价值观：每种方言反复出现的词汇会被反复强化、变成文化认同的一部分。粤语父母爱说「俾心机」（用心、认真），说明注重做事认真；湖南话爱说「展劲」「霸蛮」（用尽全力、强行把做不到的事做成）、「惯肆」（不要娇惯放纵），体现吃苦耐劳、严格要求自己；湖北话爱说「不服周」（注重不屈服，据说源自先秦楚人「不服周」，周天子大败而归）——用普通话「不服气」无法精确表达这种情感。~只会讲普通话，当然也不是没有注重的品德和价值观……但这是基础款，虽然看起来也不错，但是没有什么特色。~
  - 互补关系：~普通话和方言并不是谁比谁高级的关系，而是相互补充的关系。~ 普通话兼容性最大、能搭建横跨面最大的框架，但细节表现不足；方言就是对这些细节的修饰。普通话要表达更丰富的情感，经常需要从方言里借词，如「得瑟」「发小」「忽悠」「八卦」。
  - 敏感点越多，情感越丰富细腻：只会普通话得到的是基础框架，感受事物的分辨率相对较低。东北人、北京人口才特别好、幽默，是因为掺杂了很多方言词汇（他们并非完全说普通话），只是口音有天然优势。
  - 现状与建议：方言长期被视为落后、土的表现，有些地方甚至叫「土话」，认为说普通话才受过良好教育；随着城市化和受教育程度提高，很多家庭只用普通话而排斥方言，下一辈只会说普通话的越来越多，孩子即使会听也羞于说。与其从小学英语，不如在家里塑造说方言的环境，至少让孩子在人文方面更丰富。
  - 关于英语与新加坡：英语也能增加看世界的细腻程度，例如强调完成时，汉语普通话则弱化——「他没有毕业」到底是不知 did not graduate（读过但没读完）还是 have not yet graduated（还没到毕业的时候）；粤语口语习惯用「未」表示尚未完成（未毕业 = have not yet graduated）、用「冇」表示 did not（冇毕业 = did not graduate）。但以英语作为华人的主要语言就会取两边的公约数、去掉细腻部分，变得非英非中，新加坡人日常用英语其实也不区分完成时。作为第二语言学的英语其实是「英语的普通话」，只是框架性的，填充细节的是各种俚语、习语（相当于中文的方言），很难被其他文化的人学到。
  - 结语：语言并不只是沟通的工具，~你在用一门语言时，那你就在这门语言构建的世界观里~；多掌握一门语言、触及更多敏感点，看到的世界会更细腻。用音乐作比——1~7 之间还有半音（如 #4），一首曲子里出现几个升半音往往很好听，因为触及了我们很少听到的敏感点。如果汉语失去了方言，也就只剩下骨架。

  - 一句话概括：作者认为让自己质变的是「一本书 + 两个概念」——DDIA（工具箱深度广度）、多范式编程与最小表达力原则（语言理解与抽象能力）、领域驱动设计（方法论与架构能力），三者的共同关键点是控制复杂度。
  【方法/论点要点】
  - 核心：在 10 年程序员道路上，让作者感到质变、有大彻大悟感的是「一本书」和「两个概念」，分别对应程序员能力的三个关键方面：
    1. 一本书：~Designing Data-Intensive Applications~——对应「工具箱深度广度」。
    2. 概念一：多范式编程和最小表达力原则（least expressiveness principle）——对应「程序语言理解深度和表达抽象能力」。
    3. 概念二：领域驱动设计（Domain Driven Design）——对应「方法论、编程大道（programming in the big）和架构能力」。
  - 程序员 3 能力（引自作者另一答案）：
    1. 工具箱广度深度 / 技术选型上控制系统复杂度的能力——广度决定眼界（懂多少数据库、数据处理框架、AWS 重要 Service、著名开源框架工具）；深度决定能否在合适场景用合适的能力与工具（为什么数据库要这么实现设计、为什么 AWS 某处有缺陷如 SQS 为什么是可乱序队列、看似类似的框架在哪个本质问题上做了哪些决定性 trade-off 才分道扬镳）。
    2. 程序语言理解深度和表达抽象能力——实现上控制复杂度：懂不懂最小表达力原则、懂几种编程范式及其取舍、怎样把 code 写成诗、怎样在重重困难中坚守高聚合低耦合、程序能否从结果倒推出是哪个组件造成（系统进化的关键）、逻辑线是否清晰可见。
    3. 方法论、编程大道、架构能力——在时间跨度的整体上控制复杂度：信息不完整时怎么架构、将来信息完整了能否轻松调整；什么决定现在做、什么留给将来做；把需求获取/设计/coding/测试/安全/部署/运行监测/报警/性能/系统回馈分析/数据统计/报表等在全局安排妥当；涉及 waterfall、TDD、BDD、type driven、Agile、devOps、continuous delivery，以及技术决定业务还是业务决定技术；如何把抽象问题分解成小问题并证明这是当前信息下最好的决定。
    - 三个能力的共同关键点：~控制复杂度；控制复杂度的能力，是区分程序员能力的关键之一。~
  - 为什么是这本书、这两个概念：
    1. DDIA：作者主要工作是云技术做后端大数据模型与高性能高弹性高可用 service，之前学过 Oracle、HBase、Cassandra、Redshift、Hadoop、Spark、Kafka、Storm、Zookeeper、DynamoDB、Kinesis、SQS/SNS、AWS Lambda、Step Function、EMR 等，但学得像没头苍蝇、概念实现常记混；读了这本书三遍后一切理顺，~如果我先读了这本书，才去学上边这些东西，那么我花费的时间将是原来的3分之一到5分之一左右~。该书概括总结了数据系统在分布式/非分布式环境下的本质问题与解决方案分类，上千条引用论文指明了系统学习理论的路。
    2. 多范式编程与最小表达力原则：学了很多语言、设计模式、AOP、范型、反射、DCI 后，作者忘了为什么学它们，程序变成「程序员的行为艺术」、花式编程；了解到该原则后惊醒，回归初心——~简化程序，用尽可能简单的程序来解决尽可能复杂的问题，才是我们发明和学习了这么多技术的最终目的啊！~
    3. DDD：大到让人明白「为什么要有程序员」；小到学会用系统的方法设计/实现系统，让 VP、Director、各级开发经理、产品经理、客户、机器学习科学家等脑子里的系统，与程序员的代码组织、组件设计实现有清晰对应，并在长期时间跨度和无数需求/技术变化中坚守概念模型（concept model）与实现模型（implementation model）的一致，使小的模型改动只引起系统的小改动。
    - 比喻：DDIA 像逍遥子百年功力、莽牯朱蛤、张无忌吃的昆仑山蟠桃，给无穷内力；方法论则像北冥神功、九阳神功、易筋经，教你驾驭力量而不是自爆而亡。
  - DDD 的精神：不要看网上鱼龙混杂的资料（很多博主自己没明白就写 EventSourcing、CQRS 并说这是 DDD 架构），想了解 DDD 请去读一本 DDD 的书，作者强烈推荐《Patterns, Principles, and Practices of Domain-Driven Design》而不是 Evans 的原版。
  - DDD 实践者常用的重要 practise：跟 PM 和客户讨价还价，学会拒绝和剪裁、合理地 push back，这也是作者面试 Sr. SDE 时会考察的软技能之一。因为复杂技术实现有代价，要看换来的业务价值——核心逻辑要求的技术实现不惜代价，可有可无的功能要强势说服客户 PM 砍掉，避免支持它造成的复杂度给拓展核心业务带来困难。
  - 推荐《Worse is better》：简单要大于正确性（现在的正确未必是未来的正确）、简单大于一致性（从事务强一致转为 prefer 最终一致性是最好例子）、简单大于功能完备性（不该为非核心的功能完备性牺牲系统整体简单性）。
  - 好的程序员是简化问题和解决问题的高手，能在业务/技术/人员/文化/复杂度等多角度剪裁、衡量得失。~跳出技术思维的束缚，从全局来思考问题，我想，这就是DDD的精神吧。~
  - 尾：作者是数学系、全自学转行计算机的程序员，现在 Amazon 西雅图负责后端、做智能优化决策的部门任 tech leader，正写这 10 年如何自学的文章（书单与书评、推荐阅读顺序、踩过的坑、对有争议技术的看法）。

  - 第二，隐瞒行程：若只隐瞒了感染的时空接触行程，那只是溯源麻烦些、治安管理处罚法处理；若是感染后的行程（到处乱跑），很可能造成更广范围传播，就是刑法了。还好阳性立马收拾，不会出现以危险方法危害公共安全罪。

  【方法/论点要点】
  - 态度先行：无所谓「该不该」。问「学 vim 好不好」→好；问「不学可不可以」→可以；问「有没有必要」→没必要。身边一大群只会进插入模式当记事本用的人照样出活、升职、加薪、跳槽。别人会不会因此高看你？也许有些会，但一般不会。
  - 但可列出无法替代的优点，只是「有优点不代表劝你用」；肯不肯忍受约一个月的低效率（可能加班）是个人选择。
  - 优点一：vim 是一套经过时间证明、不用考虑「易上手」而纯粹追求「高效率」的文字编辑方案（之一）。作者不信「又便宜又好吃」：一个东西要么便宜要么好吃，「又易学效率又高」往往是「易上手的方案里效率比较高」。现代编辑器都困在「易学性」魔咒里，唯有 vim/emacs 这种上古异类（诞生于没鼠标、没图形界面、键盘没方向键、用户都是极客的年代）才能打破易学模式，专冲高效编辑演化。
  - 优点二：vim 的操作方式能用到各种软件上，各种可扩展开发工具都有人写 vim 插件；有 vim 插件说明该软件要么可扩展、要么够流行。vim 只用少量「修改键+字母」快捷键、不易与原软件冲突，有的插件还能把软件本身功能映射成 vim 键位，于是能以 vim 为核心在各种编辑器/开发环境间无痛切换，「简直是开发界的乾坤大挪移」。例子：前东家全用 eclipse、作者一人用 intellij，双方都装 vim 插件就能结对编程；2019-09-19 的 intellij 插件下载排行中 vim 插件排第七（6 百万次下载）；每次大厂出新编辑器都是他这个死硬 vim 党先去试，再推给同事（sublime、atom、vs code 都推过）。
  - 学习曲线没那么陡峭：恢复到「用其他编辑器的输入速度」最多两个星期，后面的高级内容都是赚到的新技能。
  - 插件一开始不要装太多，建议：~vim-easymotion~、~vim-surround~、~vim-multiple-cursors~、~vim-easy-align~、~vim-repeat~、~vim-fugitive~（Git 集成）、~gv.vim~（Git log）、~nerdtree~、~LeaderF~、~asyncrun.vim~、~vim-diff-enhanced~、~ranger.vim~。
  - 先选好退出插入模式的方案：把插入模式下的 ~jk~ 连按映射为 ESC，或把 ~ctrl-k~ 映射为 ESC。
  - 记忆法：j/k 谁是上跟下——中指比食指长（高），动中指向上；或记「嘴（kou）在上、老二（jiji）在下」。
  - 一星期目标状态：不需要频繁用 ~hjkl~ 移动、进插入模式基本不需要按箭头和退格。需掌握的命令清单（照录）：~ciw~、~caw~、~ci"~、~ci(~、~ce~、~diw~、~daw~、~=i(~、~viw~、~vi(~、~df.~ 等 action+text object 组合；~:数字~ 或 ~数字G~ 跳行；~w W e E b B ge gE 0 0w $~（移动）；~gg G <ctrl-f> <ctrl-b> <ctrl-d> <ctrl-u>~（翻页）；~zz zt zb <ctrl-e> <ctrl-y>~（光标不动调页面）；~H M L~（页面不动调光标到上中下）；~i I a A s r R cc o O gi~（进入编辑）；~v V ctrl-v gv~（选中）；~x dd D d+text object~（删除）；~ctrl-w~（插入模式删一个词）；~u~、~<ctrl-r>~（undo/redo）；~f F t T ;~（行内找字符）；~/~、~?~（查找/反向）；~*~、~#~（查光标单词/反向）；~n~、~gn~；~:s/查找/替换/g~、~:s/查找/替换/gc~；~y~、~p~、~P~、~yy~；~"0p~、~<ctrl-r>0~；~.~（重复上一次编辑）。
  - 组合心法：不要拆成「先 e 再 a」，而直接记成要在词尾加东西就按 ~ea~（End Append）、词前加就按 ~bi~（Begin Insert）；调换相邻两字符记 ~xp~、调换上下两行记 ~ddp~。

  - 一句话概括：一个互联网老兵的揭秘长文——上层拍脑袋立项、中层做 PPT 画饼、赌一个成一个、赔钱的业务线整条砍掉，最后 HR 一夜裁员；并点出裁员与努力能力无关、只与成本有关，大厂本质是拿故事去资本市场圈钱的投资公司。
  【方法/论点要点】
  - 前提：大厂有数百条业务线，每个部门负责的都不一样，有的赚钱有的赔钱，但通常赔钱的最多。
  - 套路：上层看中一个方向（如游戏赚钱）→大量招聘该岗位、投钱（如一年投 1000 万）、定三年盈利目标，去赌。高层之间也内卷（总裁副总裁一大批，负责业务各不同），且很多人年龄大、是投资人、根本不懂互联网，瞎指挥、眼里只有钱；员工的方案「是屎也得给老板做出臭豆腐的口感」，实现不了就假装努力加班给老板看。
  - 中层的日常：天天写 PPT，给高层做「今年实现十个亿」的汇报，一次次被打回重改，直到高层认为 PPT 真能实现十个亿。作者感叹「PPT 是个好东西，不仅能造车，还能造梦」。
  - 落空：多数业务实际根本不可能像预想那样盈利，一旦不能盈利整条业务线就被砍掉——这就是「大厂裁员常是整条业务线从上到下全裁」的原因。
  - 老板层的逻辑：投钱、找写手、做几篇新闻、搞几个概念去忽悠；上层拿着 PPT 去资本市场忽悠钱。某总裁酒后说「我们不这样的话，股票就会跌的，我们只有这样做股票才能涨」——他们根本不是做互联网，而是在股市圈钱的人；互联网公司本质就是投资公司，高层就是投资人，靠一个个故事融钱、用钱赚钱，只关心股票能不能升值，并不关心这个业务能不能做成。
  - 但不能所有业务线都赔钱（股东不傻，光靠画大饼早晚被做空），所以十条业务线九条赔钱、有一条赚钱就成功——高层是赌徒心理，「多生几个孩子，总有一个孩子能成器」。不成器的放弃、继续生继续招；大厂靠招牌不愁招不到人，赔掉一个亿不过是交学费。
  - 为什么不用原有团队：原团队在高层眼里是「败军之将」，给你三年都没搞成，已无价值、是 loser，不裁你才怪。（举例：字节跳动本地生活从 22 个城市撤退，HR 回应「系公司正常业务调整」。）
  - 业务线搞成了也照样裁一半，这叫「组织人员优化」——像建桥建设需几千人、建完只需几十人维护。
  - 裁员与你努力与否无关：什么末尾淘汰制只不过是裁你的理由，制定规则让员工内卷才对企业有利；公司只看你成本太高——35 岁被裁是因为在一家公司干十年薪资太高，与能力无关系。
  - 中层压力最大、裁员先干掉中层（负责承上启下、用来给公司交代、稳定军心地「祭旗」）；中层消息灵通，见势不妙没等裁员就提前跑路，跑之前还给没经验的小白 PUA「挺住，困难只是暂时的」。中层最苦逼：上骂、下骂、老婆骂、自己骂，辞职又不敢；爬到中层不是人生巅峰而是火山口，关键时候「跑路才是上上策」。
  - 裁员信号链：某事业部负责人离职→（一般还不到裁员时候，裁员需要过程）三个月后 HR 一夜发通告「因某某原因公司无法经营宣布裁员」，底层措手不及。HR 加班其实是在制定裁员名单；「HR 才是互联网公司效率最高的职位」；裁员公告发布前所有准备（连 n+1 的钱）提前三个月就备好，做好裁员 HR 年终奖就稳了。
  - 「情怀裁员」：有的发毕业证「恭喜你在某厂顺利毕业」，甚至有应届生入职第一天就毕业。
  - 循环继续：公司继续开新业务线、靠招牌白嫖打工者青春，招不到人就画大饼、给应届生开高薪（应届生好凑数、签合同都不看、裁起来不用 n+1），用工成本其实很廉价，很多是做给外界看的。
  - 结论：很多人不过是陪高层赌未来——老板赌钱输了再赌一把，员工赌没了未来就真的啥也没有；高层眼里只有利益没有员工。作者坚决反对拿员工前途做赌注的公司，希望企业裁员慎重、招聘别盲目。
  - 摸鱼链：底层给中层摸鱼，中层给高层摸鱼，高层给投资人摸鱼，投资人给资本市场摸鱼，资本市场给股民摸鱼——而股民就是底层员工，大家都在摸鱼。

  - 本地原文：[[file:原文/2026-10-19-一个现代汉语语法问题为什么现在被字越来越滥用了-2002871968.org][打开本地归档]]
  - 一句话概括：借余光中《翻译乃大道》的观点，说明「被」字滥用是公式化翻译对中文的戕害，并顺带批评现代汉语的「动词软化」与抽象名词泛滥，主张还原简洁明快的主动表达。
  【方法/论点要点】
  - 病根：多年来公式化翻译对中文的戕害；劣质翻译不能消化外文语法，产生畸形的中文表达，明明中文常用主动语态却受外文影响改用被动。
  - 余光中的三种句式：主动句（哥伦布发现了新大陆）、被动句（新大陆被哥伦布发现了）、无施者的被动句（新大陆被发现了）。中文以第一种为主，第三种可转回主动。
  - 中文习惯：「糖吃光了」「书读完了」，不必画蛇添足加「被」。
  - 生硬案例及改法：我不会被你这句话吓倒→你这句话吓不倒我；他被怀疑偷东西→他有偷东西的嫌疑；这意见不被人们接受→大家不接受；他被升为营长→他升任营长；他不被准许入学→他未获准入学。
  - 修养问题：汉语修养不高、表达匮乏也是「被」字泛滥的原因——「被杀」可改「遇害」「受害」，「被选为」可改「当选」，还有「挨打」「遭殃」「经人指点」「为世所重」。有人发明「累丑」，其实中文早有「憔悴」。
  - 现成案例：知乎界面「被浏览」与旁边「关注者」不搭，中文说「页面浏览量」即可；「获准同意」比生硬的被动更妥当——这是语言的劣化，不是正常流变。
  - 动词软化：英文好用抽象名词（apply pressure→press、give authorization→permit、send a communication→write、take appropriate action→act），被英国小说家斥为「文字的义肢」；中文也跟着把简洁动词改成「弱动词＋抽象名词」，令「作出」「进行」四处扩张。
  - 动词软化案例：对……作出重大贡献→贡献很大；作出十分热烈的反应→反应十分热烈；进行了详细的研究→详加研究；在老鼠身上进行试验→用老鼠试验。
  - 抽象名词的野心：拿「知名度」「可读性」取代「有名」「好看」（英文也只用形容词 readable 而非 readability）；同理「更具前瞻性」不如「更有远见」；沦为「可笑性很高」这样的怪句。
  - 建议：少用生硬欧式语法，追求简洁明快的中文；别再用「YYDS」「绝绝子」这类词代替原本丰富的表达。

  - 一句话概括：一个 18 年的 Emacser 借「动词 + 介词 + 名词」的语法框架，说明 Vim 的精髓是一套用于编辑文本的语言，而不是一堆要死记的键位。
  【方法/论点要点】
  - 立场：作者自称 18 年的非专业 Emacser，但爱用 evil（Emacs 里的 Vim 模式），因为 Vim 的精髓是它有一套编辑文本的语言。
  - 动词（对文本做什么操作）：~d~ 删除 delete、~r~ 替换 replace、~c~ 修改 change、~y~ 复制 yank、~v~ 选取 visual select。
  - 名词（处理的文本对象 text object）：~w~ 单词 word、~s~ sentence、~p~ paragraph、~t~ HTML 标签 tag，以及引号或各种括号包含的文本块。
  - 介词（界定范围或位置）：~i~「在…之内」inside、~a~「环绕…」around、~t~「到…位置前」to、~f~「到…位置上」forward。
  - 组词为句（基本语法：动词 + 介词 + 名词）：~dip~ 删除一个段落、~vis~ 选取一个句子、~ciw~ 修改一个单词、~caw~ 修改一个单词（含环绕）、~dtx~ 删到字符 x 前（不含 x）、~dfx~ 删到字符 x（含 x）。
  - 数词（数量/次数）：~c3w~ 修改三个单词、~d2w~ 删除两个单词；数词也可修饰动词，~2dw~ 两次删除单词、~3x~ 三次删除字符。
  - 言下之意：一旦按「语法」理解，命令就不再是死记硬背的散装快捷键，而是可组合、可推导的语言——这正是它「难用」却让人热衷的原因。

  动词代表了我们打算对文本进行什么操作。
  #+end_quote
  #+begin_quote
  文本编辑命令的基本语法如下：动词+介词+名词。
  #+end_quote
  #+begin_quote
  数词也可以修饰动词，表示将操作执行 n 次。
  #+end_quote

  【我的想法】

  - 一句话概括：作者认为即使把全国最顶尖的计算机和数学人才关在一起做十年也未必做得出来——MATLAB/Simulink 的壁垒不在数学运算本身，而在几十年积累的数值稳定性、正确性「工艺」和海量严谨验证。
  【方法/论点要点】
  - 核心论断：把全国最顶尖的计算机学者和数学研究者关一起让他们做十年都做不出来。
  - MATLAB 的来历：MathWorks 靠解决史诗级的「Intel CPU 浮点运算 bug」发家，此后每年招美国最优秀的计算机与数学人才开发完善，投入的钱如海一样涌入，只为实现最精密的数学计算。
  - 一个「low」例子——Ax=b：不病态、不缺秩时看似简单，但 x 能保留几位小数精度？A、b 中数值相差超过 100 万倍怎么办？误差会不会积累、算出来的 x 对不对、有效精度是多少？光这个问题就够 985 研究生研究一阵，不是随便写个高斯消元就行。
  - 二元方程组的坑：要写出对任意 a、b 取值都能正确解出 x 的求解器，起码 2-3 千行代码，因为要做大量判定、至少用 5-6 条不同路线按取值分支；即便正确，精度依然难，比如 a11=0xffffffffffffff、a22=1 这种量级差，直接扔给长整型解出来不能用，就算用 Python 的大数库稳定，也无法确知 x 有几位有效数字，还得读很多论文才能提升有效数字。
  - 更现实的难度：实际 Ax=b 常在几百万维以上，A 经常非方阵、非满秩、超定或病态；求解器要在超算上写大规模并行程序，还要考虑几百万上千万 CPU core 的不稳定性；还要把各种物理化学生物过程稳定地转成 Ax=b，这部分随便哪个领域都是博士毕业再熬十年的难度。
  - 关键在 Simulink 与「工艺」：就算给你一个功能齐全的计算包，没有经过严格测试的数据，严肃项目里没人敢用；开源 numpy 也有算法稳定性/正确性/收敛性问题，教学可以，设计 J20 气动外形这种项目没人敢用。MathWorks 的积累就是几十年花钱请各地数学家帮忙验证算法的正确性与效率。
  - 开源代码的困境：你实现的论文代码，社区喊 666，但正经公司和研究所没人敢用；用户要在重大项目里用出事故才能回头给社区反馈精度问题，这不现实。例：理论上 softmax 与 sigmoid 在二分类等价，但 sklearn 里 xgb 因计算精度不同会导致结果不一致；Intel 高精度计算库里的算法虽过时，一年 license 却要不少钱，因为人家确保特定版本 Intel CPU 上的数值精度，你安心调用即可。
  - 类比光刻机：光刻机原理不难，难在工艺，而工艺被封锁；MATLAB 一样难在「工艺」——算法要求稳定收敛、数值确定性好，可能全中国都没人知道怎么做（举例 Quake 平方根倒数那个不开源技巧，有几人会）。
  - 结论：MATLAB 要搞出来得经过非常长时间的积累，或立马召集顶尖科学家研究，但没有哪个公司愿意投入巨额钱和人力去做还没有收获的事，大家都忙着发展。所以用上自己的 MATLAB「应该还要蛮久的」。
