*你是不是觉得：学完了 C 语言就是只能坐下数学题，在黑框里输出一串数字，做个水仙花、杨辉三角。觉得它并不能编辑出一个啥子游戏或者软件出来。*

阿里的库森学长在读书是也是这种感受，平时老师上课时基本都在用古老的软件vc6.0，能用vs2013的都屈指可数！

而且课程设计都是做过通讯录、图书馆系统，一直都是黑呼呼的窗口，哪还有什么编程兴趣。

都在讲C语言是最接近与底层的一门高级语言，C语言很强大，可以开发嵌入式啊，做操作系统啊，开发数据库啊。

C的确可以做很多事情，这是 *纯c写的超级马里奥：*

[[https://picx.zhimg.com/50/v2-fa97680aa03fff2892213b826b1ee34d_720w.jpg?source=2c26e567]]

但这些对大一刚学完C语言的同学们过于遥远，开发难度很大。

*而且大一课程教的只是c语言语法，是与平台无关的，不调用图形接口，就没法写windows应用。*

*不调用操作系统网络接口，就没法写通信程序。不学习linux内核,你就不会用c写linux内核.*

这里给小伙伴们分享几个C语言能做的小游戏、小项目，从基础到进阶，学完C语言的基础就能做，你会发现C语言真的能做很多事！

** 二、进阶版的项目

*1、Webbench*

[[https://picx.zhimg.com/50/v2-615bed66ff749483909d5921a7a03085_720w.jpg?source=2c26e567]]

*Webbench* 是一个在 Linux 下使用的非常简单的网站压测工具。

它使用fork()模拟多个客户端同时访问我们设定的URL，测试网站在压力下工作的性能。

最多可以模拟 3 万个并发连接去测试网站的负载能力。Webbench使用C语言编写，代码非常简洁，源码加起来不到 600 行。

*项目地址： <u>[http://home.tiscali.cz/~cz210552/webbench.html](http://home.tiscali.cz/~cz210552/webbench.html)</u>*

2、 *Tinyhttpd*

[[https://picx.zhimg.com/50/v2-55198f5f99d79804fe8e3bf97027feb4_720w.jpg?source=2c26e567]]

*tinyhttpd* 是一个超轻量型Http Server，使用C语言开发，全部代码只有 502 行（包括注释），附带一个简单的 Client

可以通过阅读这段代码理解一个 Http Server 的本质。

*项目地址： <u>[http://sourceforge.net/projects/tinyhttpd/](http://sourceforge.net/projects/tinyhttpd/)</u>*

** *3、cJSON**

*cJSON* 是C语言中的一个JSON编解码器，非常轻量级，C文件只有 500 多行，速度也非常理想。

虽然cJSON功能不是非常强大，但cJSON的小身板和速度是最值得赞赏的。

其代码被非常好地维护着，结构也简单易懂，可以作为一个非常好的C语言项目进行学习。

*项目主页： <u>[http://sourceforge.net/projects/cjson/](http://sourceforge.net/projects/cjson/)</u>*

** 4、 *Libev**

*libev* 是一个开源的事件驱动库，基于 epoll、kqueue 等 OS 提供的基础设施。

其以高效出名，它可以将 IO 事件、定时器、和信号统一起来，统一放在事件处理这一套框架下处理。

基于 Reactor 模式，效率较高，并且代码精简（4.15 版本 8000 多行），是学习事件驱动编程的很好的资源。

*项目地址： <u>[http://software.schmorp.de/pkg/libev.html](http://software.schmorp.de/pkg/libev.html)</u>*

** *5、Lua**

[[https://picx.zhimg.com/50/v2-150680b955bf6d6a1648a1409cafa825_720w.jpg?source=2c26e567]]

*Lua* 很棒，在任何支持 ANSI C 编译器的平台上都可以轻松编译通过。

Lua 的代码数量足够小，5.1.4 仅仅 1.5W 行，去掉空白行和注释估计能到 1W 行。

*项目地址：* [http://www.lua.org/](http://www.lua.org/)
