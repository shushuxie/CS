我愿称之为：今年 GitHub 上最让人颅内高潮的一个中文开源项目。先说结论：如果你对中国历史、古诗词、地理哪怕有一丁点兴趣，这个网站值得你立刻收藏——它解决了一个困扰我二十年的问题,一些地名，到底他妈在哪儿？ 我不是标题党。直接上数据：这个叫 江山时序 ( [[https://deanchen.me/jiangshan-map/][https://deanchen.me/jiangshan-map/]] ) 的项目，上过 GitHub Trending 日榜第1，现在 8000+ star，纯前端零依赖，作者一个人从课本插图的执念做到开源爆款。但 star 数这种事，知乎读者早见惯了。真正让我破防的是打开它的那三分钟。

[[https://pic1.zhimg.com/v2-d898cdf619724170067927c4988bcfa6_1440w.jpg]]

一、拖动时间轴的那一刻，历史忽然活了，我们这代人学历史，脑子里全是静态的、一张一张的图。秦朝一张，汉朝一张，唐朝一张——但从来没人告诉你它们之间是怎么变过去的。江山时序干了一件特别朴素、又特别难的事：把公元前 403 年（三家分晋，《资治通鉴》开篇）一直到今天，2400 多年、18个历史时期，做进一张可以来回拖动的古舆图里。你把时间轴往后一拖，就能眼睁睁看着：战国七雄怎么被秦一个个吞掉，最后只剩大秦一块版图；汉武帝怎么一路打通河西走廊；唐朝的安西四镇、元代的宣政院（西藏）、晚清曾纪泽收复伊犁； 直到近现代，版图从秋海棠一点点变成雄鸡。而且它有个细节特别戳我：每切一个阶段，上一阶段的疆域会用朱砂虚线残影叠出来，哪块地得了、哪块地丢了，一目了然。这不是在 看图，这是在眼睁睁看一个文明涨缩呼吸。时间轴上还实时显示当年的在位皇帝和年号——拖到741年，气泡上写着唐玄宗·开元二十九年。你突然就理解为什么诗人写开元两个字那么深情。 ---

二、点开任何一座城，读它 2400 年的身世，这是我最想安利的第二个功能。读书时那些地名——建康、黄州、蓝关、朱仙镇——我以前只知道它们是诗里的字，不知道它们是地上实实在在的点。现在你在地图上点一下长安，它会弹出一张点地溯源卡片：这座城在 2400 年里换过多少个名字、归过哪个郡、哪个道、哪个路、哪个省，哪些朝代在这里建过都，以及这一块地上具体发生过什么大事（玄武门之变就在长安，水淹七军在樊城，风波亭在临安）。点一下事件，时间轴直接穿越回那一年。这个功能，本质上是在回答一个很终极的问题：长安两个字，到底沉淀了多少层历史？

三、点人溯事：跟着苏东坡、李白、玄奘走一遍人生。第三个玩法，直接把情绪价值拉满。在搜索框里输入苏轼，地图会用编号图钉，把他一生的行迹画出来：出川赴京→密州赏月→乌台诗案→贬黄州写《赤壁赋》 →惠州→跨海到海南儋州。每切下一站，地图上的王朝版图、年份、皇帝年号，都跟着他的人生同步流转。你看着他从北宋的繁华走到天涯海角，旁边还配着《史记》《出师表》的原句。李白、杜甫、玄奘、张骞、诸葛亮、王阳明……都有。你甚至可以一次输入两个人（比如李白杜甫高适），看他们的人生轨迹在哪一年、哪座城交汇—理解同途两个字的浪漫，隔着1200 年还是能击中你。

四、隐藏彩蛋：测测你在古代能当几品官，作者还塞了个小游戏：舆图寻址 挑战。地图隐去所有地名，给你一条当朝掌故线索（比如请在【西汉】版图上标出武威），让你凭山川水系的直觉盲猜扎针，按距离算分。十道题做完，系统给你封官—太史令·舆图，还是州郡从事，看你自己。我是州郡从事，不说了，有点伤自尊。

五、说点技术向的，这才是它真正的分水岭，这项目最让我respect的不是好看，而是作者把它做成了一个基础设施，别人做的是个网站，他做的是一个给 AI 用的历史地理引擎，这个前瞻性，在中文开源里很少见。

六、一点克制的冷水，我也不是无脑吹。两点：1.历史疆域是示意性近似，不是测绘边界，别拿它去论证领土问题——作者自己都写清楚了，还引了谭其《中国历史地图集》做校对，态度很严谨。2.郡/州/府级精细边界用的是 CHGIS 数据，只限学术非商业用途，不能二次分发。作者把这条单独拎出来说，这版权意识值得夸。最后，写这篇文章的时候，我反复在想一个词：知其所从来，我们背了那么多诗、考了那么多试，却很少有人告诉你，王维送别的阳关在哪，韩愈勒马的蓝关在哪，苏东坡被贬的黄州在今天的哪个省。江山时序这件事，某种意义上是在给中文世界补一堂空间的历史课。而它出自一个开源作者之手，免费、开放、还漂亮。在线体验： [[https://deanchen.me/jiangshan-map/][https://deanchen.me/jiangshan-map/]] ， GitHub 仓库： [[https://github.com/DeanChensj/jiangshan-map][https://github.com/DeanChensj/jiangshan-map]]

建议先收藏，再点开，我保证，你会回来给这篇文章点赞的。
