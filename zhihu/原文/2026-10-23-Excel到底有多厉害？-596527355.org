** 一、Excel VBA爬取新浪微博

[[https://www.zhihu.com/video/1130313516304920576][Excel VBA爬取新浪微博https://www.zhihu.com/video/1130313516304920576]]

是用Python来做爬虫，其实Excel也可以！用不到50行的代码就可以爬取一个博主的所有微博，并下载高清微博配图！

#+begin_src text
Private Declare PtrSafe Function URLDownloadToFile Lib "urlmon" Alias "URLDownloadToFileA" (ByVal pCaller As LongPtr, ByVal szURL As String, ByVal szFileName As String, ByVal dwReserved As LongPtr, ByVal lpfnCB As LongPtr) As LongPtr
Private Declare Sub Sleep Lib "kernel32.dll" (ByVal dwMilliseconds As Long)
Sub weibo()

With CreateObject("WinHttp.WinHttpRequest.5.1")

    For i = 1 To 81
      .Open "GET", "https://m.weibo.cn/api/container/getIndex?jumpfrom=weibocom&type=uid&containerid=1076033669102477&value=3669102477&page=" & i, False
      .setRequestHeader "user-agent", "Mozilla/5.0 (iPhone; CPU iPhone OS 11_0 like Mac OS X) AppleWebKit/604.1.38 (KHTML, like Gecko) Version/11.0 Mobile/15A372 Safari/604.1"
      .Send
      response = .responsetext
      Call json_arr_to_vba(response)
      Sleep Int((300 * Rnd) + 100)
    Next i

End With

End Sub

Sub json_arr_to_vba(strjson)
  Set jsobj = CreateObject("ScriptControl")
  jsobj.Language = "JScript"
  jsfun = "function json_vba(jsondata){a=eval('(' + jsondata + ')');return a.data.cards;}"
  jsobj.addcode jsfun
  Set vbadata = jsobj.Run("json_vba", strjson)

  For Each wb In vbadata
      j = Sheets("微博").Range("A65536").End(xlUp).Row
      For i = 1 To 34
          field = Sheets("微博").Cells(1, i).Value
          On Error Resume Next:
          Sheets("微博").Cells(j + 1, i).Value = CallByName(wb.mblog, field, VbGet)
      Next i

      '下载图片
      pics = CallByName(wb.mblog, "pics", VbGet)

      For Each pic In CallByName(wb.mblog, "pics", VbGet):
          '高清原图
          picurl = CallByName(CallByName(pic, "large", VbGet), "url", VbGet)
          '压缩图片
          'picurl = CallByName(pic, "url", VbGet)
          pid = CallByName(pic, "pid", VbGet)
          imgarr = Split(picurl, ".")
          imgtype = imgarr(UBound(imgarr))
          URLDownloadToFile 0, picurl, ThisWorkbook.Path & "\wbpic\" & pid & "." & imgtype, 0, 0
      Next     
  Next
End Sub
#+end_src

** ②、源码解析

这里主要是引入两个Windows api，URLDownloadToFile是为了下载图片使用，kernel32.dll是为了防爬措施，程序随机暂定一定时间再执行。

#+end_src

weibo()是主过程，这里使用WinHttp模拟请求，WinHttp对象在销毁前可以自行处理cookie相关信息，可以省去很多工作，创建WinHttp对象以后使用一个for循环来修改page参数，关于页数的计算，微博主页可以看到微博总条数，一页返回10条微博，那么就知道总共需要循环多少页了。 *重要强调：WinHttp对象必须设置：user-agent* ，否则api接口不会返回数据。中间调用了json_arr_to_vba过程，这个过程主要用于解析json数据，并写入到Excel工作表中，接着sleep一个随机时间，主要目的是规避防爬措施。

VBA不能直接解析json数据，或者说解析比较麻烦，这个需要借助JavaScript，3-7行都是创建js对象，jsfun实际是一个js函数，这个函数也很简单，实际只有三行代码，返回的是api接口返回数据中的cards数组，然后使用for each遍历这个数组，for循环1-34实际是api数据字段名称，我把字段都放在的微博工作表的第一行，循环读取，使用On Error Resume Next是因为并不是每条微博所有字段都存在，所以需要容错。 *重要强调：不要把js对象赋值给VBA对象，这样取不到想要的数据，比如：large=CallByName(pic, "large", VbGet)，这样赋值以后large中已经不是js对象，所有就不包含原来的信息的，这就是为什么取下一级json的时候使用CallByName(CallByName(pic, "large", VbGet), "url", VbGet)这样的形式。* 解析出来图片原图url以后，就可以使用URLDownloadToFile把图片下载到本地了，到这就完成了新浪微博文本及图片的下载。
