我的插件：

- [asyncrun.vim](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/asyncrun.vim)：异步运行 shell 命令，并把结果实时输出到下方的 quickfix 窗口。
- [asynctasks.vim](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/asynctasks.vim)：给 Vim 引入类似 vscode 的任务系统。
- [vim-quickui](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/vim-quickui)：给 Vim 8.2 / NeoVim 0.4 及以上增加版本一系列基础 ui 控件。
- [vim-auto-popmenu](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/vim-auto-popmenu)：170行小脚本提供类似 YCM 的补全体验（字典/buffer补全）。
- [vim-dict](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/vim-dict)：比较丰富的各种语言的词典数据，以及自动加载词典，包含英文 c40k 单词表。
- [vim-terminal-help](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/vim-terminal-help)：终端使用小助手，更方便的使用内置终端。
- [vim-cppman](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/vim-cppman)：在 Vim 中直接查看 cppman/man pages，支持 windows。
- [vim-preview](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/quickmenu.vim)：快速预览函数定义/原型，并且方便的再多个定义中切换预览。
- [vim-keysound](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/vim-keysound)：在 Vim 中打字时播放音效，让你编程充满节奏感。
- [vim-init](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/vim-init)：轻量级 Vim 配置框架，全中文注释，教学用。
- [asyncrun.extra](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/asyncrun.extra)：为 asyncrun 提供额外 runner。
- [gutentags-plus](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/gutentags_plus)：提供其他编辑器没有的 GNU Global 使用体验。
- [quickmenu.vim](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/quickmenu.vim)：给 Vim 添加一个功能目录，解决很多快捷键容易被遗忘的问题。

修改别人的插件：

- [argtextobj](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/vim/blob/master/site/opt/argtextobj.vim)：给 Vim 添加 “函数参数” 文本对象，使用 via 选中参数，cia 改写当前参数，dia 删除参数。（这个项目是 fork 别人的，我修了一堆 bug）。
- [indent-object](https://link.zhihu.com/?target=https%3A//github.com/skywind3000/vim/blob/master/site/opt/indent-object.vim)：给 Vim 添加 “缩进” 文本对象，使用 vii 选中同一层缩进层次的代码，这个项目也是在别人的基础上进行优化的。
