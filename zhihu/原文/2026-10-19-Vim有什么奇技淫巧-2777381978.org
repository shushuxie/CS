12. 想制造输出？太容易了，随时随地用你喜欢的语言！

比如我想要0-9，直接输入

#+begin_src python
for i in range(10):
    print(i)
#+end_src

V选中两行程序，然后按下 *!* ，输入python3回车，你就可以得到文本了，同理，你想要bash脚本的，可以输入bash，执行输出！

#+begin_src bash
for i in ~seq 0 9~;
do
    echo $i
done
#+end_src

这在vim中叫做filter，非常好用，可以和诸多程序联动，比如执行sort，可以得到排序后的输出！

26. 标记的使用，大家相比都用过m{a-zA-Z}来标记一处地点，但是你知道吗，vim中有一些默认的标记，能够使你快速进行编辑和移动，比如符号 *.* 表示最近编辑的位置， *0-9* 表示最近使用的文件，而 *^* 表示最近插入的位置， *~* 表示上一次跳转前的位置， *“* 表示上一次退出文件的位置， *[* 表示上一次修改的开始处， *]* 表示上一次修改的结尾处，我最常用的是 *.* 和 *~* ，能够马上跳转到我刚才编辑的地方以及上一次跳转的地方，熟悉了的话，非常方便（ *这个建议下意识练习，非常实用* )

28. 编辑文件的时候忘记了使用最高权限而无法保存怎么办？

你可以使用

#+begin_src vim
:w !sudo tee %
#+end_src

我给你拆解一下：首先是w命令是write命令(就和平常写的wq一样那个)， 然后是!命令，这是将文本内容通过管道传递给shell命令了，后面你可以看作在shell中运行，然后是tee是写命令，然后是%，在这里vim会将它展开为文件名字(如果不信，你可以使用:!echo %查看)， 因此这句话就是将文件内容传递给外面有权限的shell命令tee去写入(这个命令建议记住!)，最后vim会报一个警告，这是因为文件被修改了，按下L(也即Load)就可以了。

[[https://picx.zhimg.com/50/v2-5a25f3f61d27267df97a0c44b56f29fc_720w.gif?source=2c26e567]]

31. 巧用vim, quickfix的errorformat， 有的时候我们会遇到想要快速跳转到日志报错的对应处，但是当前vim先有的compiler没有合适的，那么我们可以自定义errorformat，然后快速跳转解决问题：

：set errorformat=this\ is\ a\ path\ %m\ :%f\ %l

其中%m是错误信息， %f是文件路径,  %l是行号,  空格要使用\ 转义，这样简单的格式就能够让我们快速构建自己的错误解决列表，快速跳转，非常方便。

然后，可以看到输出内容我们只想要eth和Link关键字相关的行,因此这里先搜索

然后我们把不包含这些字段的行删除:
