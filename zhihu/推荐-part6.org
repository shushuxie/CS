  - 一句话概括：把 C++ 入门拆成「语言」和「标准库」两块，语言给三阶梯书目、标准库给侯捷的书和配套课，路线很短但每一步都指名道姓。
  【方法/论点要点】
  - 总纲：学 C++ 分两大部分——C++ 语言和 C++ 标准库，两部分都掌握才算真正入门，才能从事 C++ 开发岗位。
  - 语言部分第一阶梯：语言基础，推荐《C++ Primer（中文版 第5版）》。
  - 第二阶梯：进一步提升，读《Effective C++（第3版 中文版）》和《More Effective C++（中文版）》，作用是写出更规范、更专业的 C++ 代码。
  - 第三阶梯：有 C 基础的可以直接看博览网（Boolan）的《C++面向对象开发》课程，该课对前两本书的重点难点做了深入剖析；主讲人就是上面两本书的译者侯捷。
  - 标准库部分第一项：经典之作是侯捷的《STL源码剖析》。
  - 标准库部分第二项：觉得书难啃，可以看对应的在线课《STL标准库与泛型编程》。
  - 另有综合版《C++开发工程师》微专业，适合想系统学习 C++ 的人。
  - 正文较短（不到 700 字），没有展开每本书的读法、章节顺序或练习方式，主要以带链接的书目形式呈现。

  - 一句话概括：一份 14 个 Java 开源项目的清单，从字符串工具、内存表到内存泄漏检测和设计模式示例都有，每个都给了仓库地址和一句话定位，适合当「练手项目池」而不是学习路线。
  【方法/论点要点】
  - 全文共列 14 个项目，按原文顺序：
  - Bootique：面向无容器、可运行的 Java 应用，能基于模块创建 REST 服务、Web 应用、DB 迁移任务等；目的是把应用从 Java 容器里解放出来，让开发者收回 main() 方法，并内置了一些命令。
  - 99-problems：一系列 Java 问题的合集，用来练习逻辑编程，可用 Java 8、Scala 或 Haskell 解答，目标是找到最优雅的解法；难度分级，耗时从 15 分钟到几小时；另推荐 Java Deathmatch 做游戏化挑战。
  - Strman-java：专做字符串操作的库，发布在 Maven 上，加个依赖即可；提供追加字符串、按索引取字符、取起止之间的数组等函数。
  - Dex：数据分析工具，可提取、转换、可视化数据并做预测；支持 50 多种可视化模式（世界地图、时间线等），可与 R 的运行实例整合做统计分析和预测。
  - Tablesaw：内存数据表，含数据工具和面向列的存储格式；设计理念是「很小的任务不需要分布式分析」，单机可处理多达 200 万行；支持从 RDBMS 和 CSV 导入、增删列、压缩列存储。
  - Chronicle Map：面向低延迟或多进程应用的内存 key-value 存储，典型场景是交易和金融市场；可替换单机上的 Redis 之类慢速 KV 存储，也能把部分应用状态移出 Java 堆，降低堆大小和 GC 压力。
  - Gumshoe：监控应用性能统计数据，能精确定位到代码行，拿到调用栈和单个栈帧的统计，从而分析 TCP/UDP 等资源使用情况；统计结果可筛选和可视化。
  - SoundSea：搜歌与下载工具，用 iTunes 的元数据和专辑封面，歌曲从 Pleer.com 下载，可按高、低或 VBR 比特率筛选，还能当迷你播放器。
  - LeakCanary：Square 开源的内存泄漏检测库，在 debug 版中检测 Java 内存泄漏，配置后出现泄漏会自动通知。
  - ND4J：把 Python 那套直观的科学计算工具带进 JVM，面向生产环境、速度快、占用 RAM 小；提供通用 n 维数组对象、含 GPU 的多平台支持、线性代数与信号处理函数。
  - Automon：结合 AOP 以声明式方式监控 Java 代码、JDK 和依赖库，可追踪方法调用时间、异常次数，并把数据存到所选工具里展示。
  - Jvm-tools（SJK）：一组用于 JVM 排错、监控和性能分析的命令行工具，基于 JVM 标准检测接口（JMX 等）补充了更适合常用排错操作的逻辑。
  - Awesome-java：Java 框架、库和软件的合集，按类别整理，方便查找。
  - Java-design-pattern：用 Java 实现的设计模式集合，作者认为设计模式提供经过验证的开发范式，能加快开发、避免小问题酿成大故障、提升代码可读性。

  - 一句话概括：先用十张排序动画把数据结构讲活，再给出一张从「计算机科学速成课」到组成原理、操作系统、编译原理、网络、数据结构与算法的完整书单和公开课清单，本质是一份计算机基础自学地图。
  【方法/论点要点】
  - 作者自述把「图解算法」项目放到 GitHub 后两天登上 trending 第一，回答里所有算法都配了动画，目的是面试没思路时能靠动画联想起来。
  - 十个经典排序的步骤（每条配一张 gif）：
  - 冒泡：比较相邻元素，前者大于后者就交换；对每一对相邻元素做同样工作，一轮后末尾是最大值；对越来越少的所有元素重复，直到没有一对需要比较。
  - 选择：在未排序序列中找到最小（大）元素放到起始位置；再从剩余元素中继续找最小（大）放到已排序末尾；重复直到全部排完。
  - 插入：把第一个元素看作有序序列，其余为未排序序列；从头扫描未排序序列，把每个元素插入有序序列的适当位置（相等时插到相等元素后面）。
  - 希尔：选增量序列 t1…tk（ti>tj，tk=1）；按增量个数做 k 趟排序；每趟按增量 ti 把序列分成若干子序列，分别做直接插入排序；增量为 1 时整个表作为一个序列处理。
  - 归并：申请大小为两有序序列之和的空间；两个指针分别指向两序列起始位置；比较所指元素，较小者放入合并空间并后移指针；重复直到某一指针到尾；把另一序列剩余元素直接复制过去。
  - 快排：挑一个基准 pivot；把所有小于基准的放前面、大于的放后面（分区 partition），基准落到中间位置；再递归排序左右两个子数列。
  - 堆排序：建堆 H[0…n-1]；把堆首（最大值）与堆尾互换；堆尺寸减 1 并调用 shift_down(0) 把新堆顶调到合适位置；重复直到堆尺寸为 1。
  - 计数：O(n) 扫一遍得到 min 和 max；开长度 max-min+1 的数组 B；B 的下标记录该值出现次数；遍历 B 输出元素及对应个数。
  - 桶排序：设固定数量的空桶；把数据放进对应桶；对每个非空桶内部排序；按顺序拼接非空桶。
  - 基数排序：把所有待比较正整数补齐到同样位数；从最低位开始依次排序；从低位排到最高位后序列即有序。
  - 评论区要求后补了猴子排序和睡眠排序（只给外链，未列步骤）。
  - 校招/社招的基础占比判断：校招是计算机基础 90% + 专业知识 10%，社招反过来是 20% / 80%，所以基础都是必考。
  - 作者举的例子说明基础的实际价值：设计权限接口时，熟悉数据结构会自然想到用 bitmap，用一个 uint64 存 64 种细分权限；不熟则可能花一周写十几个糟糕接口。
  - 推荐的学习方式：视频课程 + 看书。第一遍视频快速过完，后面边看边思考，不要抄代码，作业隔天再写；多尝试、减少路径依赖，时不时和视频里的方案对着干看会发生什么。
  - 零、开始：花 10 小时看《计算机科学速成课》（Crash Course，共 40 集、每集约 10 分钟，B 站有汉化），跟不上可用 0.75 倍速。
  - 一、计算机组成原理：先读《计算机是怎样跑起来的》《程序是怎样跑起来的》《网络是怎样连接的》这套通俗入门，再上《计算机组成与设计》《深入理解计算机系统》《计算机体系结构：量化研究方法》；视频推荐伯克利 SICP/CS61A（至少学完前三章并做完练习），太难可换 How to Design Programs，另有 Harvard CS50、MIT 6.001；国内有清华刘卫东、哈工大刘宏伟 135 讲。
  - 二、操作系统：书《现代操作系统》《操作系统导论》《深入理解计算机系统》《自己动手写操作系统》《操作系统真象还原》；视频有 MIT 6.828（基于 Unix v6 的 xv6）、Udacity Advanced OS、Coursera 北大课程；国内清华课程与哈工大李治军 32 讲。
  - 三、编译原理：作者强调它不能随便入门，需要先积累组成原理、操作系统甚至数学基础，且非常难、非常枯燥；书《编译器设计（第二版）》《编译原理》；视频有 Stanford CS143/CS243/CS343、CMU 15-411 等，国内哈工大 81 集、东南大学廖力 64 讲。
  - 四、计算机网络：要懂 Socket 编程、TCP/IP 模型、OSI 七层，知道数据包如何层层包装再层层拆包；书《网络是怎么连接的》《计算机网络-自顶向下方法》《图解HTTP》；视频有 Wireshark labs、Stanford CS144，国内谢希仁第七版、哈工大李全龙。
  - 五、数据结构与算法：核心命题是「程序 = 数据结构 + 算法」，学习分三步——入门（科普读物）、实践（实现较容易的结构与算法）、原理（背后的数学）。
  - 算法书按三档推荐：入门《大话数据结构》（400 多页，理论讲得有趣）和《算法图解》（不到 200 页，主打图解），共同缺点是缺细节、不系统；基础《数据结构与算法分析》（有 C、C++、Java 三个语言版本，系统严谨又不特别难）；面试实战《剑指 offer》（覆盖经典面试题）、《编程珠玑》（9 分，强在海量数据处理技巧）、《编程之美》（微软工程师合著，题目偏难、不系统，适合面 Google/Facebook 前自测）。
  - 算法视频：Stanford 的 Algorithms（Tim Roughgarden，偏理论）、UCSD 的数据结构与算法（约 100 个编码问题）、Princeton 的 Algorithms Part I/II（Java 实现 + 性能分析）；国内浙大陈越/何钦铭、北大张铭 C++ 版、武大李春葆。
  - 可视化工具：visualgo.net（支持中文）和 USFCA 的 Data Structure Visualization。

  - Java 语言基础：String 是值类型还是引用类型、String 底层、final、自动装箱、泛型擦除、深拷贝与浅拷贝、匿名内部类编译出的 class、内部类与外部类互访、构造器可重载但不可重写、为什么集合类没有实现 Cloneable 和 Serializable。
  - 集合：HashMap 原理是重点，讲清负载因子（默认 0.75，越大空间利用越充分但查找越慢，越小越浪费空间）、put 时用 hashCode 定位桶、碰撞后才用 equals 逐个比较、JDK7 在链表头插入、hash() 重新计算哈希是为防止低质量的 hashCode 实现、indexFor 用 `h & (length-1)` 等价取模但更快；另有 ConcurrentHashMap 原理、ArrayList 与 LinkedList 对比。

  - 一句话概括：从轴体、轴厂、键帽讲到分价位机型，把机械键盘的选购变量一次讲清，并按 300 元以下、300-800、800 以上给了具体型号。
  【方法/论点要点】
  - 机械键盘与薄膜的区别：薄膜是一整片塑料薄膜，成本低但寿命和手感都差；机械键盘每个键下有独立轴体，反馈更强，不同轴手感不同，还能换键帽、部分支持热插拔轴体
  - 优点：寿命长（好的可用十多年）、久用后手感变化小、轴体多样、可 6 键以上无冲甚至全键无冲、键帽可 DIY
  - 缺点：售价偏高，稍精致就要 400 元以上，几千元也不稀奇；防水略差
  - 黑轴：压力 80、触发 1.5mm、无段落、寿命 5000 万-6000 万次；压力克数最高、触发最短，适合游戏，打字太累
  - 青轴：压力 60、触发 2.4mm、段落感清脆、寿命 2000 万次；手感像电灯开关，适合文字工作者，但噪音最大
  - 茶轴：压力 60、触发 2.0mm、段落感较钝、寿命 5000 万次；被称为万能轴，手感接近薄膜，游戏打字都行，但没特色
  - 红轴：压力 40、触发 2.0mm、无段落、寿命 5000 万次；等于轻量化黑轴，力度轻、直上直下，容易误触且造价最高
  - 选轴办法：去一二线城市的实体店试；或买试轴器，国产轴十几块、樱桃轴约三十块
  - 轴厂：Cherry（德国，1953 年成立，MX Switch 最经典，单轴约 2 元）；凯华（国产一哥，speed 与 box 系列口碑好，box 防水防灰，约 1.3 元）；佳达隆（外号低配樱桃，青轴好评但品控不稳，约 0.9 元）；高特（廉价键盘常见，故障率与臭轴率高，约 1 元）；康腾特（高特分裂后所建，不到 0.8 元）
  - 键帽材质：ABS 最便宜、易打油；POM 坚硬耐用抗打油、手感光滑，是 Cherry 原厂御用；PBT 更硬更耐打油、抗氧化抗腐蚀，手感更粗糙
  - 购买渠道：首推京东，大牌旗舰店多在此，可买延保，退换货优于天猫
