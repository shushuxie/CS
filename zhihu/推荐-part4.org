  - 一句话概括：作者列出 22 款最满意的 PC 软件，多为免费、开源、跨平台的商用软件替代品，覆盖压缩、虚拟机、截图、下载、远程、数据库、编辑器、PDF、图像、视频、加密等日常场景。
  【方法/论点要点】
  - 首批十款：
    1. 7-zip——大道至简，界面就是 Windows 原生的样子。
    2. Oracle VM VirtualBox——支持快照、高级网络配置、跨平台、后台运行。
    3. Greenshot——开源、轻巧且强大的截图工具，自带简单的图片编辑功能。
    4. Motrix——开源的基于 aria2 的多线程下载工具，IDM 的免费开源跨平台替代。
    5. MobaXterm——免费版比 Xshell 强大得多，SSH、SFTP、VNC、RDP 一站式服务，还支持 Multi-Exec。
    6. Dbeaver CE——支持几乎所有数据库协议，在线自动下载 JDBC 驱动。
    7. TeamViewer——远程桌面软件，可内网穿透，个人免费版无弹窗和广告。
    8. VSCode。
    9. Notepad 3——支持正则表达式查找替换、自动高亮，适合临时编辑文本（VSCode 偏重）。
    10. SumatraPDF——老牌小巧的 PDF 阅读器，比福昕更轻量级、无广告推广。
  - 补充的十二款：
    11. darktable——开源、跨平台的数码暗房，支持 RAW 格式照片润色，功能强大，Lightroom 替代品。
    12. OpenShot——开源、跨平台、小巧的视频编辑软件，可应付日常剪辑，替代会声会影。
    13. win32diskimager——支持将 img 和 iso 镜像写入 U 盘；主流 Linux 发行版都是 Hybrid ISO，可运行、可安装。
    14. rufus——用途同上，但灌入 ISO 后 U 盘剩余空间仍然可用。
    15. DiskGenius——国产磁盘分区管理软件，可恢复被 win32diskimager 和 rufus 灌入 ISO 的 U 盘。
    16. mpv——开源、跨平台、简洁、绿色的视频播放软件，比 VLC 更简洁更纯粹。
    17. Inkscape——开源、跨平台的矢量图绘制软件，操作习惯类似 CorelDraw。
    18. Gimp——开源、跨平台的图片编辑工具，替代 Photoshop。
    19. Scribus——开源、跨平台的排版系统，替代 InDesign（对中文支持不太好）。
    20. Blender——开源、跨平台的 3D 建模软件，同时也是强大的视频编辑软件。
    21. VeraCrypt——开源、跨平台的加密软件，继承 TrueCrypt 的遗产。
    22. AESCrypt——开源、跨平台的加密软件，支持 256 位 AES 加密，没有界面，右键加密解密完事。
  - 选型思路：能用免费、开源、跨平台的替代品，就不花钱买商业软件。

  - 本地原文：[[file:原文/2026-10-19-有哪些你看了以后大呼过瘾的编程书-2278198495.org][打开本地归档]]
  - 一句话概括：作者推荐被书名耽误的神书《数据密集型应用系统设计》（DDIA）——豆瓣 9.7、Goodreads 4.72，适合每一位后端/CRUD 程序员，并建议结合 MIT 6.824 分布式系统课程一起看。
  【方法/论点要点】
  - 推荐书籍：《Designing Data-Intensive Application》，简称 DDIA，国内译《数据密集型应用系统设计》。豆瓣评分 9.7（近 90% 打五星），Goodreads 评分 4.72（近 80% 打五星）。
  - 适合人群：~这本书适合每一位做后端开发的程序员阅读，尤其适合每一位 CRUD 程序员阅读！~ 作者说它有点被书名耽误，不要以为只是给数据处理岗看的。
  - 主要内容：分布式数据库、数据分区、事务、分布式系统等；从数据模型与查询语言、数据编码，到数据复制和分区，再到事务、一致性共识，以及故障与部分失效、不可靠网络和时钟等挑战，都结合实例深入讲解，工业与学术平衡得很好。例如讲 MVCC（多版本并发控制）时，图解了 PostgreSQL 如何基于 MVCC 实现快照级别隔离。
  - 作者的核心观点：
    - 数据是后端系统的核心，所做的事情都围绕数据展开。
    - 现在大部分应用是数据密集型（data-intensive）而非计算密集型（compute-intensive），系统瓶颈通常来自数据处理而非 CPU。
    - 数据库、消息队列、缓存等中间件可统称数据系统（data system），彼此界限越来越模糊，如 Redis 当消息队列、Kafka 带类似数据库的持久保证。
  - 亮点举例：讲 ACID 时指出~原子性，隔离性和持久性是数据库的属性，而一致性（在 ACID 意义上）是应用程序的属性~，所以字母 C 不属于 ACID；讲数据复制时介绍主从复制易理解、不用担心冲突，多主/无主复制在节点失效、网络中断或延迟抖动时更可靠，但代价是系统复杂性和弱一致性。
  - 配套学习：MIT 6.824 分布式系统课程。油管全英文视频 https://www.youtube.com/channel/UC_7WrbZTCODu1o_kfUMq88g/videos ；B 站中文翻译合集 https://www.bilibili.com/video/av91748150 ；中文文字版 https://mit-public-courses-cn-translatio.gitbook.io/mit6-824/ 。作者称这门课的 Lab 非常不错。
  - 作者背景：Martin Kleppmann 是剑桥大学计算机科学与技术系的研究助理和讲师，参与 Automerge、Apache Avro、Apache Samza 等知名开源项目，博客 https://martin.kleppmann.com/ 。

  - 一句话概括：力荐 Robert Nystrom 花近 10 年写成的《Crafting Interpreters》——用 Java 和 C 各实现一遍解释器（讲语法、语义与实现、bytecode/VM/GC），并论证「每个想深入学习编程的人都该去理解一门编程语言是怎么实现的」。
  【方法/论点要点】
  - 作者背景：Robert Nystrom 有 20 年工作经验，在 EA 干过 9 年多，2010 年入职 Google、目前在 Dart 项目。2009 年开始写设计模式书《Game Programming Patterns》，写到一半发现对编程语言实现很感兴趣，2014 年完成第一本（评价很高、电子版完全公开，适合学设计模式）；随后断断续续写第二本，2020 年完成《Crafting Interpreters》，前后接近 10 年。
  - 成书质量：作者在《Crafting "Crafting Interpreters"》里详细记录了制作过程，插图自己手画、配文手写再扫描成电子版；成书质量极高，且成书和代码完全免费阅读。写技术书投入产出比很低，只有纯粹的热情才能让人花这么多年。
  - 为何要学编程语言实现：①克服对语言的恐惧——解释器、编译器不过是另外一个程序，我们可以自己实现常见语法和特性，语言是可以改变和理解的工具而非黑盒；②这是绝佳的提升编程技能的方式；③工作中会接触各种小语言和 DSL，parser 或编译相关技能可能有用。
  - 学习体会：作者本科挂了「形式语言和自动机」，觉得枯燥（要手画状态机），工作后找具体代码来看才理解状态机如何应用；因此学编程最重要的是读代码和写代码——他自己通过读《Essentials of programming languages》(EOPL) 学到很多。理解编程语言时，Parser 只是第一步、也是最不重要的一步（做法已很成熟规范），更重要的是语法、语义和实现；编译部分更底层高深，现在 LLVM 是常用编译后端，理解一门语言的实现可以先从一个小语言的解释器入手。
  - 本书内容：详细讲解一个解释器的两遍实现——第一遍用 Java，注重主要概念和原理；第二遍用 C，涉及 bytecode、VM、GC，注重优化和底层实现。这些主题对非编译器从业者已足够。
  - 比喻：编程语言的实现比很多日常项目难，但值得想深入学习编程的人锻炼——「长跑运动员有时在脚踝上绑重物、或在空气稀薄的高海拔训练，卸下包袱时相对轻松的四肢和富含氧气的空气让他们跑得更远更快」。

  【方法/论点要点】
  - ~cppman~：C++ 98/11/14 手册查询（Linux/MacOS）。用法如 ~cppman std::thread~ 查手册；速度快、比开网页方便，可配到终端编辑器快捷键显示光标下 token 的 reference；Windows 不能用但可在 Cygwin 装；默认在线请求 cppreference.com/cplusplus.com，可花半小时全缓存到本地做离线帮助。
  - ~mcedit~：终端下的 NotePad++（midnight commander 内置编辑器）。安装 ~apt-get install mc~ 或 ~brew install mc~；Debian 手册里排在 vim/emacs 之后、官网 wiki 列为五款最好用终端编辑器之一；F9 / ALT_F 或点首行显示下拉菜单，多文件多子窗口、对话框式搜索/配置、~SHIFT+方向键~ 区域选择复制粘贴、F11 弹 User Menu（可按文件后缀展示代码片段/编译运行/F11 规则可在 Menu->Options->Menu File 配置）；初次使用记得关掉 ~visible tabs~。
  - ~icdiff~：分屏显示 diff，比传统 diff 更明白、效果比 sdiff 好不少，可配置成 git 默认 diff 工具。
  - ~pm~：在 bash / zsh 中迅速切换项目目录。~pm add 名称~ 存当前目录、~pm list~ 查看、~pm go 名称~ 切换、~pm remove 名称~ 删除。
  - ~cgasm~：命令行查询汇编指令。支持本地模糊搜索（如 ~cgasm aes~），~cgasm -v aesenc~ 显示与 Intel 开发手册一致的指令字节码、编码模式、状态影响、伪操作码和等价 Intrinsic。
  - ~owncloud~ / ~owncloudcmd~：DropBox 的开源替代，口号「你的数据，你掌握」。需自建服务端（有 VPS 或公网固定 IP 的服务器可用 docker 五分钟拉起）；把 ~owncloudcmd~ 放进 crontab 每五分钟同步 ~/.cloud/~ 目录，一处修改各处自动同步。
  - ~ncdu~：基于 ncurses 的可视化空间分析程序。光标上下移动、回车进入目录查看最新占用，很快揪出占空间最大的罪魁祸首。
  - ~glances~：比 htop/top 更强大的替代者，信息更丰富；除命令行外还提供页面服务，可随时从网页查看服务器状态。
  - ~mc~（midnight commander）：内容浏览/预览，类似 Windows 的 Total Commander；光标浏览文件、TAB 切左右窗口、支持鼠标和内容预览，F3 唤出 mcedit 预览、F4 编辑。
  - ~ranger~：另一款内容预览软件，界面不如 mc 漂亮、标记拷贝较弱，但预览做得很好，习惯 vim 键位会觉得比 mc 好不少；~j/k~ 移动、右栏自动预览、左键回退上一层、~q~ 退出。
  - ~dstat~：vmstat 的代替者，输出更美观、整洁、强大。
  - ~cheat~：命令行笔记 / cheat sheet。可自建 ~/.cheat/redis~ 等文件，用 ~cheat redis~ 显示；自带很多常用 cheat sheet（~cheat tar~、~cheat vim~、~cheat rsync~）；比查网页或 evernote 快，可用环境变量 ~DEFAULT_CHEAT_DIR~ 设定个人 cheat 目录并纳入 dotfiles 多机同步。
  - ~multitail~：多重 tail。相比「开多个 tab」或 tmux+tail 更强：日志色彩高亮、窗口自动管理/调整大小、多个日志窗口可合并成一个查看、临时显示/隐藏某窗口、对所有日志统一关键字搜索、日志过滤与外部正则分析、内置 tcpdump/apache/squid/strace 等常见服务高亮模板。
  - ~bro~：以用例为主的帮助系统（bropages）。所有用例由用户提供、投票筛选、按票数排序；如 ~bro cut~，可对解释投赞成/反对票；安装先装 ruby 与 ruby-dev 再 ~gem install bropages~，比官方文档的「知乎式筛选」更易筛出最好的帮助。
  - 相关阅读：终端调试哪家强、为什么说 zsh 是 shell 中的极品、有哪些好用的 bash 技巧。

  【方法/论点要点】
  - 概念澄清：严格说 Linux 只是操作系统的「内核」，通常所说的「Linux 操作系统」指采用 Linux 作为内核的操作系统。
  - 分类维度一（是否商业版）：商业公司维护的商业版（代表 RedHat Enterprise Linux）与开源社区维护的免费发行版（Ubuntu、CentOS、Debian 等）；开源≠免费，付费的是服务/商业支持，个人多用免费版。
  - 分类维度二（包管理器）：包管理器负责软件的安装、卸载、升级、查询，省去处理软件依赖的麻烦。DPKG（dpkg/apt，代表 Debian、Ubuntu）、RPM（rpm/yum，代表 RedHat、CentOS）、Pacman（Arch、Manjaro）、DNF（Fedora）、Zypper（SUSE）、Portage（emerge，Gentoo）。
  - Debian：与 Ubuntu 同派系，界面不如 Ubuntu 华丽但稳定，适合做服务器，开源圈子广泛使用。
  - Ubuntu：界面华丽、包管理完善、社区活跃、个人用户多，比较大众化。
  - RedHat：商业版 Linux，多用于企业生产环境，提供完善商业支持，性能和稳定性有保障。
  - CentOS：基于 RedHat 商业版社区编译重发布，完全开源免费，比一般免费发行版更稳定，企业常用作服务器系统。
  - Fedora：与 RedHat 同派系、同属红帽公司，免费发行，侧重新技术试验，稳定性考量略次要。
  - SUSE：有大公司支持，主要用于企业用户。
  - Arch：适合好奇心强的人尝鲜，官方 Wiki 好、AUR 仓库繁荣，适合 DIY 玩家。
  - Manjaro：Arch 的衍生分支，兼具 Arch 优点又对用户友好，注重体验和稳定性，安装使用方便。
  - Gentoo：适合极客折腾和特殊定制，小众；有系统洁癖、控制欲强、什么都想自己编译定制的人的天堂。
  - 选用建议：完全零基础、想入门体验 Linux 界面——Ubuntu；喜欢折腾 DIY、好奇心强——Arch / Manjaro / Gentoo；部署服务、看重稳定性——CentOS / Debian。最终仍看个人需求和兴趣。

  - 安全性：驾驶技术与专注比配置重要一百倍；碰撞测试最高 64km/h 是行业瓶颈。主动安全（疲劳提醒、辅助驾驶、AEB）多多益善，被动安全看车身结构、气囊、防撞梁；防撞梁别神化，主要在低速碰撞减少维修成本。看安全主要看气囊数（5 座车≥6 个才够好，只有 2 个不建议考虑）和碰撞测试（参考美国 IIHS，国内参考中保研）。
  - 选车理念：世界上没有完美的车，只有最适合自己的车；先定预算再结合用途，坚持自己内心想要的车，别被亲友和道德绑架。

  - 专题二 基本算法思想：贪心、动态规划四步解题法模板（基础/进阶/再进阶三篇）、分治、递归与动态规划、正则表达式匹配从暴力到 DP。
  - 专题三 排序算法：手撕排序、十大经典排序动画与解析（配代码）、十大排序算法分析。
  - 专题四 搜索：广度优先搜索面试题、BFS 与解题套路、从二叉树问题看深度优先搜索。
  - 专题五 查找：二分查找详解、二分查找模板与题型、无 bug 的二分查找。
  - 专题六 字符串匹配：BM 算法的坏字符与好后缀规则、七分钟理解 KMP、BF 算法、DP 之 KMP 详解。
  - 专题七 线性表：有序数组/链表去重、数组中第 K 个最大元素、数组遍历加四个条件、缺失的第一个正数、二维数组中的查找、单调栈、链表实现栈和队列、栈与队列互实现、链表实现 LRU。
  - 专题八 散列表：什么是哈希表、哈希洪水攻击、哈希表面试题、如何判断元素在亿级数据中是否存在。
  - 专题九 树：二叉树高频面试题、二分搜索树、LeetCode 二叉树总结、DFS 视角、AVL 平衡二叉树、MySQL 为何用 B+ 树、字典树、B 树与 B+ 树对比、最小生成树、2-3-4 树、2-3 树、Trie 树动画。
  - 专题十 图：拓扑排序、图论基础与存储结构、图的两种遍历、最短路径。
  - 书单分三档：入门看《大话数据结构》（理论有趣、结合生活例子、400 多页可两天读完）和《算法图解》（不到 200 页、主打图解）；基础看《数据结构和算法分析》（有 C、C++、Java 三个版本，系统严谨又不算太难）；面试实战看《剑指 offer》（覆盖常见经典面试题）、《编程珠玑》（9 分，强在海量数据处理技巧）、《编程之美》（微软工程师所写，题目偏难、不太系统，适合面 Google/Facebook 前自测）。
  - 作者提醒：不要一上来啃《算法导论》，容易挫败放弃；入门书共同的缺点是缺细节、不够系统严谨。
  - 刷题四阶段：① 纯小白，概念陌生，LeetCode 第一题都做不出；② 已入门，Easy 会做、Medium 纠结，基础不牢；③ 刷了几百道，有自己的模板，周赛有时能全过；④ 以 beat 100% 为目标。达到第二阶段可应付中小公司，第三阶段字节、腾讯的算法环节没问题。
  - 四条建议：① 目标国内大厂至少刷 200 道高频题，不必刷完 2500 道；② 面试前一周以看题和模板为主（如回溯模板）；③ 难度循序渐进，国内大厂考察基本不超过 LeetCode 中等，不必纠结偏题怪题，觉得难可先从《剑指 Offer》开始；④ 按算法分类集中刷，一段时间只刷链表、再刷二叉树，便于总结虚拟头节点、双指针、快慢指针这类套路。
  - 补充「算法在工作中的作用」：用 OAuth2 授权场景说明可用 bitmap 存权限，一个 uint64 划分 64 种细分权限，每位代表一项授权；并以 Linux 内核里的二叉搜索树、哈希表、红黑树、Radix 树，以及缓存淘汰的 LRU 算法为例。

  - 一句话概括：按从入门到进阶排了 13 本 Java 书，每本都交代了适读阶段、该读哪几章、哪些章节可以跳过，还顺带给了大量配套读书笔记链接，是一份带取舍意见的书单而不只是罗列。
  【方法/论点要点】
  - 第一本《Head First Java》：作者现在会优先推荐它而非《Java 编程思想》《Java 核心技术卷》，理由是趣味性甩开好几条街，图文并茂，还有游戏、拼图、解谜题。章节要点：第 1 章 Java 原理/简史/程序结构；第 2 章面向对象（继承、覆盖）；第 3 章变量（引用变量存对象地址、数组也是对象）；第 4 章方法（实参形参、值传递与引用传递、== 与 equals）；第 5 章程序设计与实现步骤；第 6 章 API（ArrayList）；第 7 章继承与多态（覆盖和重载）；第 8 章接口与抽象类（超类 Object）；第 9 章构造器与垃圾收集（对象在堆、引用在栈，失去最后一个引用即被回收）；第 10 章静态成员（final、常量、数字格式化、日期）；第 11 章异常；第 12、13 章 GUI 与 Swing（事件处理机制）；第 14 章序列化与文件 IO（Serializable）；第 15 章 Socket 与多线程；第 16 章集合与泛型；第 17 章打包发布；第 18 章远程服务调用。
  - 第二本《Java 核心技术卷一》：唯一能和《Java 编程思想》媲美的入门书，单看技术前者更好、思想层面后者更好；前者已出到第 10 版（2016），后者停在第 4 版（2007）。前九章（概述、环境、基本结构、对象与类、继承、接口、lambda 与内部类、异常/断言/日志、泛型、集合）必看；第 10-12 章 AWT/Swing 可不学，但事件驱动-监听-回调机制要懂；第 13 章 Applet 没必要学；第 14 章并发是初级到高手的必经之路。
  - 第三本《Java 编程思想》：豆瓣 9.1，880 页，第四版代码基于 JDK 1.5。作者 Bruce Eckel 2017 年出了第五版但改名《On Java 8》、只有电子版；示例代码开源在 GitHub 的 BruceEckel/OnJava8-Examples，中文译本在 LingCoder/OnJava8。
  - 第四本《Effective Java》：第三版含 90 条经验规则，每条相对独立，可随意挑小节读；作者 Josh Bloch 曾任 Google 首席 Java 架构师；主要涉及 java.lang、java.util、java.io 包；中文在线翻译在 sjsdfg/effective-java-3rd-chinese。
  - 第五本《Java 网络编程》：整体评价不高、吐槽更多，但对打基础有用，涵盖 TCP/IP 与 UDP/IP、网络输入输出、DNS 交互、定位与下载网络资源、HTTP（REST、头部、Cookie）、Socket 通信。
  - 第六本《Java 并发编程实战》：并发编程参考手册，从并发与线程安全基本概念出发，讲线程提升吞吐、识别可并发任务、提高响应性、保证执行预期、提升性能与可伸缩性；缺点是翻译枯燥，读起来要耐住性子。
  - 第七本《深入理解 Java 虚拟机》（周志明，第 2 版）：五部分——Java 技术体系与发展历程；自动内存管理（内存区域划分、内存溢出原因、垃圾收集算法与收集器）；类文件结构、类加载机制、字节码执行引擎；编译与代码优化（泛型、自动装箱拆箱、条件编译等语法糖原理、HotSpot 即时编译器）；高效并发与 JVM 内存模型。
  - 第八本《Java 性能权威指南》：讲用 4 个基本原则提升性能测试效果、用 JDK 自带工具收集性能数据、理解 JIT 的优缺点、调优垃圾收集器、优化多线程。
  - 第九本《代码整洁之道》：例子用 Java 写，Java 程序员有天然优势；核心是 Keep It Simple Stupid。书中对整洁代码的定义：每个方法每个类只专注一件事、命名顾名思义；简单直接不隐藏设计者意图；应当有单元测试；拒绝重复。
  - 第十本《设计模式之禅》（秦小波，第 2 版）：五部分——第 1-6 章讲单一职责、里氏替换、依赖倒置、接口隔离、迪米特、开闭六大原则；第 7-29 章讲 23 种设计模式；第 30-33 章比较相关模式；第 34-36 章讲模式混合使用；第 37-38 章讲 5 种新设计模式。
  - 第十一本《Java 开发手册》（阿里）：覆盖编程规约、异常日志、单元测试、安全规约、MySQL 数据库、工程结构、设计规约 7 个部分，作为代码规范标准可帮人养成习惯、降维护难度。
  - 第十二本《重构——改善既有的代码设计》：看起来需要精力和耐力，建议放在前面这些书之后读，对重新审视现有代码帮助极大。
  - 第十三本《算法》：作者以自己的经历劝新人多投入数据结构与算法，认为这是决定技术高度的地基；嫌《算法》太枯燥可先看《趣学算法》《啊哈算法》这类趣味入门书。他还反驳「算法工作用不到」：跳槽时大厂爱考，读源码也用得上，且算法是少数能有效训练大脑思考能力的途径。
