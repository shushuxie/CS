  - 一句话概括：明确否定「抄代码」的学习价值——除了看得仔细点、练了打字，和自己盯着看没差别；真正决定水平的是先练内功（算法与递归）再练招式（语言与框架）。
  【方法/论点要点】
  - 结论：照着别人的代码敲一遍，除了让你看得仔细点、练了打字，其它没有任何帮助，和自己盯着代码仔细看是一样的，效率不高。
  - 唯一例外：如果抄的时候带上了思考，那也算有效果——思考才是核心，「不是看，不是写，而是思考」。
  - 作者用 ACM 经历佐证判断力：大学参加全国 ACM，校赛一等奖、市赛一等奖，清华决赛二等奖；清华比赛 4 小时做出 2 道题即二等奖，而进入决赛的都是各高校层层选拔的选手。
  - 基本判断：计算机的重点是用已有知识构建功能，构建步骤是固定的，需要的是牢固的基础知识和思考能力。
  - 内功第一条——数据结构与经典算法：做书本习题时，要在自己不知道解法的情况下先写一遍，而不是看完解答再重复抄一遍。代码可能只有十几行，写不花时间，思考才花时间；作者曾为一题思考几天。
  - 内功第二条——学会写递归，再把同一功能改写成循环实现，用来再提升一步思考能力。
  - 内功的意义：掌握这两条之后，即使刚接触计算机，水平也已超过入门、达到中级；语言用法只是「招式」，多写几次就会，而内功可以迁移到任何语言，「万法归一」。
  - 顺序很重要：先掌握核心算法与思想，再去熟悉语言、方法调用和框架，之后才足以胜任大部分互联网公司职位。
  - 进阶第一条——有深度地思考：写代码的时间应该很少，大部分时间在脑中想清楚怎么实现才合理、高效，然后一次写完，而不是边写边改边想；思考难度要「跳一下够得着」，循序渐进。
  - 进阶第二条——在脑海中提前构建程序，不过分依赖调试工具：写一点就跑一次、报错再改，这种循环既浪费时间又提升有限。应该一口气写完再运行，看到 bug 先别急着改，先回想自己写的时候哪里有问题，再逐步修正。
  - 作者称这套方法练成后的收益是：别人四小时的功能你可能一小时写完，且写一遍就接近预期结果。

  - 一句话概括：直说《鸟哥的Linux私房菜》被过度神化——二十多章里常用的只占两三章，更像个人笔记合集，然后按「用 Linux」和「深耕 Linux」两种情况各推荐了一本书。
  【方法/论点要点】
  - 作者用 Linux 超过 4 年，多次在空闲时尝试读《鸟哥的Linux私房菜》，无一例外都半途而废。
  - 核心判断：这本书被过度神化。它不是不好，但要分「使用 Linux」和「深耕 Linux」两种情况来看。
  - 如果目标只是使用或熟练使用 Linux，作者认为这本书是「从入门到放弃」的不错选择。
  - 内容构成：内存、显卡、配置、分区、vim、内核等；整本二十多章，常用的只占两三章，仅配置和介绍就占了 4 章，很多人看完这 4 章就没力气了。
  - 性质判断：更像个人博客、笔记的集合；拿它当主要学习依托会耗费大量时间，而且很多内容连运维人员都用不到，更不用说前端、后端、算法方向的开发者。
  - 推荐一：《Linux就该这么学》，刘遄著。基于 RHEL、Ubuntu、CentOS 等主流发行版，作者是 Red Hat 认证的 Linux 讲师；覆盖基本命令、shell、用户和文件权限、存储、文件传输、网络等，循序渐进、浅显易懂，适合初学者，也适合有基础想进一步熟练的人。
  - 推荐二：《Linux命令行大全》，William E. Shotts, Jr. 著，郭光伟、郝记生译。作者认为大多数 Linux 使用者日常面对的问题无非命令、文件操作、权限、环境、网络、进程几项，把这些学明白，再结合帮助文档和网络资料，足以应付绝大多数互联网/IT 工作；这本书正是按这些层面条理清晰地展开，针对文件、权限、网络、vi、shell 讲解，层次分明、没有冗余。
  - 文末顺带推广了作者自己的 GitHub 书库项目与专栏。

* 学习 C++ 到底有什么好处？  :观点:C++:底层:图形学:

  :链接:  https://www.zhihu.com/question/328171823/answer/727835037

  - 本地原文：[[file:原文/2026-10-20-学习C到底有什么好处-727835037.org][打开本地归档]]
  - 一句话概括：不直接回答「有什么好处」，而是从「屏幕上的一个点阵怎么被管起来」一路问到窗口管理、3D 渲染和引擎，最后落到一个判断：C++ 的价值不是写业务，而是让你能挖到技术的根。
  【方法/论点要点】
  - 开篇定调：学 C++ 本身教不会你编程，你得主动、不断扩展知识领域；写个学生管理系统只是开端。
  - 用「图形界面到底是什么」做例子：屏幕是色点组成的点阵，1920×1080@24bit 就是 1080 行、每行 1920 个点，每点用 RGB 表示 2^24 种颜色，每种原色 8 bit、取值 0~255。一切界面最终都要变成这个点阵，人眼分辨不出点，才看成一张图。
  - 于是问题层层升级：程序要管理这个巨大点阵；操作系统还要同时跑很多程序、显示很多窗口；窗口之间怎么不互相干扰、怎么处理遮挡、看不见的窗口要不要每秒 60 帧更新、没变过的窗口能不能不每帧重画以省掉计算。
  - 作者把这一串问题称为「学生管理系统的超级放大版、复杂版」——为了解决它，人们搞出复杂的数据结构和针对性算法，还不够，又从 MFC 那种复杂消息循环和对话框数据交换，发展到 Qt/GTK/WPF 这类界面与逻辑分离的架构，而这需要面向对象。
  - 算一下 60 帧刷新 1920×1080 的计算量，结论是只有 C/C++ 系语言 hold 得住，其他语言做容易浪费太多性能。
  - 3D 场景：几十上百万个三角形拼模型，实时更新位置，模拟几个光源处理光照和反射，再用虚拟摄像机算出该看到的数据投射到屏幕。
  - 演化链条：CPU 逐顶点处理太笨拙 → 加 MMX/SSE/3D NOW 等 SIMD 指令集 → 性能仍不够 → 显卡 → GPU → 实时光线追踪。
  - 分工：Qt/GTK/WPF 帮我们管常规窗口，OpenGL、DX9/10/11/12 帮我们和显卡打交道，A3D/Unity 之类引擎则把图形、音频、动画、模型以及状态机、地图导航、碰撞检测都打包好。
  - 核心好处：贴近底层、贴近硬件或性能要求严格的程序，往往只能用 C/C++ 系写出来；别的语言不是不能写，但「多少都差点意思」。
  - 学习建议：不建议学 C++ 时着急用各种框架。因为学框架用任何语言都行（C# 到 Python），但写一个 Qt/GTK、写一个 MySQL、写一个 GCC 这类「把计算机体系结构挖到根子」的挑战，只有 C/C++ 鼓励你做，也只有它有海量优质开源资源可参考。
  - 收益描述：别人追着 Qt 新版本研究新 API 怎么调，你能说出「这个新特性其实我知道它是怎么实现的」；别人学用数据库，你写玩具数据库；别人学 hive，你写自己的 big-table/map-reduce。这类原理性代码量不大，但难度更高。
  - 结论：想做面向用户的东西，不建议用 C++，因为繁琐；想挖各种技术的根子，C/C++ 是最犀利的武器，没有之一。
  【原文摘录】
  #+begin_quote
  学C++本身是教不会你编程的。你需要主动的、不断的扩展自己的知识领域。
  #+end_quote
  #+begin_quote
  学C++的好处是，这类贴近底层、贴近硬件或者性能要求严格的程序，往往只能用C/C++系语言才写的出来——用其他语言倒也不是不能写，但多少都差点意思。
  #+end_quote
  #+begin_quote
  正因此，其实我是不太建议学C++时着急用各种框架的。
  #+end_quote
  #+begin_quote
  总之，如果你想学着做一些面向用户的东西，其实并不建议你用C++。因为用它实现这类东西往往会比较繁琐。但如果你想挖到各种技术的根子，那么C/C++就是最最犀利的武器——没有之一。
  #+end_quote
  【我的想法】
  这是少数把「C++ 的好处」讲成认知收益而不是性能数字的回答，路径也很聪明：从一个像素推到窗口管理器，再推到 GPU，读者自然就理解了为什么这一层需要手动管理内存。但它有个隐含前提——你得真的去写那些「玩具」；如果只是读完觉得爽，收获为零。现实里更划算的做法是先挑一个具体的东西（比如写个软光栅器）再回头补语言特性，而不是先学完 C++ 再找用途。

  - 一句话概括：不直接谈立法，而是把「为什么企业宁可让人加班也不肯多放假」还原成一套工厂逻辑——工厂真正的主角是机器，休息是人的概念、停摆是机器的犯罪，于是工时、请假负罪感、年龄淘汰全都成了「把机器用尽」的副产品；值得收是因为它用一个统一的解释框架串起了五个看似无关的职场困惑。
  【方法/论点要点】
  - 切入点（一个脑洞）：建议社科学生去工厂当一段流水线工——「在华夏，流水线才是人类学家天选的田野考察场地」，在流水线待一周就能参透「东亚打工五大矛盾」。
  - 五大矛盾（作者归纳，全文由此展开）：
    一、为什么公司假期短工时长，却不爱减工时多放假？休息不是能让人更有生产力吗？
    二、为什么有些老板赚钱总爱「降本增效」这一招，而不去想提高毛利率、品牌价值？
    三、为什么老板总在打工人身上省钱，而不提高福利、激励员工多赚钱？
    四、为什么企业有那么多年龄淘汰机制，年轻人总有「未老先衰」的感觉？
    五、为什么公司把服从、纪律当成首要美德，经济上行捉考勤，经济下行也捉考勤？
  - 个人经历：大学毕业后去一家港资企业当管培生，被派驻内地工厂，培训一开始就在车间打螺丝、贴标志。
  - 当时无法理解的车间规则：上厕所要申请、要拿离岗证；一天上 12 小时、两班倒，连周日都想安排生产；请假时主管认为你应该有负罪感，「你甚至会有种自己在『阻住地球运转』的感觉」。
  - 关键转折：后来才明白「我没搞清楚主次，不明白谁是主角，谁是 NPC」——一间工厂的主角从来不是工人、不是管理者、甚至不是老板，**真正的主角是机器**，工厂的一切都围绕机器运转。
  - 原因（重资产逻辑）：投资一家工厂最大头的支出不是人力、不是科技，而是机器；工厂的成败取决于核心资产机器「有没有被极大程度地用尽」——「只要它在动，钱就会流入；但它一停下，就是世界末日」。主管与工人只是确保机器运转的配角。
  - 推论一（休息的罪感）：在工业思维里，休息就是停摆，而停摆是一种犯罪；所以请假时主管觉得你该内疚。
  - 推论二（休息是人的概念）：机器不需要休息，只需要保养与维护；机器长期不开动反而难重新进入状态（像车子久不启动），所以老板怕放长假、怕员工「心散」——他眼中的模范职员是 24 小时住在公司的人。
  - 推论三（折旧→年龄淘汰）：机器技术迭代快、折旧也快，买下新机器若不在限定时间内用尽就会亏本；精明的管理者会疯狂使用、等折旧完再换更先进的新设备。「这些现象本质上都不是因为工厂主天性残酷，纯粹是利害使然」——**「我们不是在变老，我们是在折旧」**，「用了十年的人才可能还年轻，但用了十年的机器不会有人想要」。
  - 文化印证：《摩登时代》——人进入生产线、被卷进机器、成为机器的一部分（默片，记住的是意象不是台词）。
  - 延伸：实习结束后发现自己「以为离开了流水线，其实只是去到了一个更大的流水线上」；工厂思维无孔不入，无论传统工厂还是互联网「大厂」，你始终在这座世界工厂里。
  - 立场收尾：「社会科学不是灰暗的科学。探讨现象不是要你认同，不是要你认命，而是要你去认清事情的真相，从而找到我们在这个时代要走的出路。」
  - 注 1（宏观补充）：东亚模式常被批评重投资、轻消费，消费占比 日本 53–55%、韩国 48%；工厂毛利率常只有个位数、赚的是辛苦钱，所以老板赚到钱倾向买新设备而不是分给员工（「反正你不干，有的是人干」）；当一个社会多数老板都是工厂主，资源就持续流向投资而非消费，最终要么大量出口往外卷、要么本土打价格战，疯狂内卷。
  - 注 2：为未来牺牲当下有一个吊诡——「有时候你牺牲了当下，却不一定捱得到未来」。
  - 注 3：把服从、纪律当首要美德是工厂逻辑，因为工厂最需要的是「顺贴的零件、听话的机器」，它最看重的不是创造力、不是判断力。
  - 注 4：世界工厂给的是三个数字（最巨大的生产力、最庞大的贸易顺差、最齐全的供应链），但数字与硬件之外，「他们享有着『世界工厂』的产品，而我们才是真正住在『世界工厂』里的人」。

  - 一句话概括：把职业倦怠拆成情绪衰竭、去人格化、成就感低落三维，用「高蜡烛先灭」解释为什么越优秀的人越容易烧尽，再给出调速度、加空气、换大杯子三招，结论是休假跳槽都治不了根。
  【方法/论点要点】
  - 普遍性数据：美国心理学会称 53% 的人认为工作让他们极度疲累；《中国「工作倦怠指数」调查报告》显示七成职场人轻微倦怠、13% 重度。
  - 概念出处：1974 年美国临床心理学家弗罗伊登贝格尔（Herbert J. Freudenberger）首次提出 burnout，指面对过度工作时身体与情绪的极度疲劳；他自己做医生时也曾对病人死活毫无感觉，后来发现教师、警察、护士等服务型行业同样如此。
  - 定义：由工作引发的情感、精神与体能上的入不敷出感——有能力做事，却没动力去做。
  - 《马氏工作倦怠量表》三个维度：情绪衰竭（心好累，不想干活、不想担事、对重新上班恐惧）、去人格化（对组织同事不满，对他人痛苦冷淡）、成就感低落（觉得自己什么都不行、怀疑价值）。
  - 作者顺手用《三体》戏说：叶文洁因对人类失望而发信号，属去人格化；监听员工作无成就感、心累，属情绪衰竭加低成就感，故事源于两个职业倦怠者。
  - 「Burn Out」即燃烧殆尽。蜡烛实验：一高一矮两支蜡烛同时罩上杯子，高的先灭——因为二氧化碳热气体上升占据上半部，高火苗先被笼罩。
  - 隐喻：蜡烛高度=能力，火苗=工作状态，空气=动力，二氧化碳=压力。越优秀的人越容易倦怠：好的蜡烛需要大空间、烧得最起劲，也最快感到窒息。
  - 招数一「调整燃烧速度」：意识到自己烧得太猛，重划工作边界，尤其调整完美主义。作者称完美主义是最重要的压力源，它设置根本完不成的任务，达不到又自我怀疑，是多种心理疾病的源头。
  - 招数二「降低二氧化碳，加入空气」，三种严重二氧化碳：重复性工作（可用弹性工时、游戏化应对）、缺乏人际回应（主动向上级要反馈、多撩拨同事与工作对象）、缺乏控制感（要求高、控制低、资源少时最易失去控制感；应细分目标，聚焦可控部分，放手不可控部分）。
  - 招数三「换更大的杯子」：主动要求并创造更大空间；工作实在没法「吸氧」，就转战兴趣、爱好、家庭、健康或读书。
  - 心法 A 预防为主：倦怠不是一天养成，要常自查。频繁把工作带回家、睡醒还是累、自制力下降（如暴饮暴食），就是轻微倦怠的信号，此时调整很容易。
  - 心法 B「倦可以，怠不得」：「倦」是疲倦厌倦的心理感受，「怠」是怠工懈怠的外在行为。刚觉得倦就主动怠下来会更疲劳，形成恶性循环。
  - 应对心态：把倦怠当老朋友，「矮油，您又来啦」，用症状表定位倦怠点，再用三招调整；像跑步三公里的极限期，保持节奏熬过去就能再跑一大截。
  - 结论：倦怠与时代特征相关，大范围流行、周期性出现、无法幸免也无法根治；休假或跳槽只能缓解表面，高手是能快速从倦怠里反弹的人。文中未给出休假、跳槽有效的具体证据，落脚点在自我调节。

  - 一句话概括：借「状元之死」事件说清一件事：非虚构的真实标准与新闻一致，任何细节都不能虚构，所谓「模糊化处理」不是豁免牌。并解释了非虚构如何从高冷概念变成自媒体爽文的外衣。
  【方法/论点要点】
  - 事件起点：「状元之死」刷屏后，主创团队声明写「文章不是新闻报道，这是一篇非虚构写作……在细节上，我们做了许多真实情况的模糊化处理」。作者称之为「一等一的车祸现场，完了还要碰瓷」。
  - 他的翻译：这段话的意思是「我们不是写新闻，别用真实要求我们，非虚构写作稍微虚构一下怎么了」。
  - 核心判断：非虚构写作肯定、一定、必须、只能遵守零妥协的「真实原则」，任何一个细节都不能虚构；在真实性标准上，它和新闻报道并无二致，区别在表现手法和艺术价值。
  - 为什么容易躺枪：非虚构是舶来品，在中国看着热闹，实则无甚大众基础；非从业者不太在意其内涵与精神，「文爽即可」。于是被偷梁换柱，甚至被高举为「虚构」的豁免牌。
  - 引专栏作家宋金波《〈一个出身寒门的状元之死〉是「权健式文字保健品」》的判断：《状元之死》与保健品一样，已突破「无益」与「恶」之间的界限；咪蒙团队的鸡汤更接近「无益」，而这篇的仿真式诱导、尤其文末利用「慈善」欺骗读者，正在试图突破「恶」的边界。
  - 历史脉络：非虚构诞生至今半个多世纪，在中国一度只在专业圈打转；2010年《人民文学》倡导「非虚构」，才有点潮流样子，但只是敦促作家走出书斋、远离「二手生活」。
  - 升温标志：2015年诺奖颁给阿列克谢耶维奇。非虚构作家在瑞典文学院历来不受待见，上一部诺奖非虚构作品是1953年丘吉尔的《二战回忆录》。阿列写的是二战、古拉格群岛、苏联解体、切尔诺贝利核灾难、阿富汗战争，作家邱华栋称之为「非虚构文学的胜利」。
  - 进中国后的分流：批判精神一部分由现实主义作家继承，另一部分被媒体借鉴，成为非虚构的分支——特稿。此后批判功能和空间逐渐被压抑，只剩真实性和文学性，在自媒体时代迎来「春天」。
  - 2016年影视资本涌入，冲出一批非虚构作品，大多售出百万级影视版权，市场一度相信非虚构的商业模式找到了。
  - 但严守「祖制」违背商业规律：海量采访、搜集、极其严谨的求证与写作，不符合效率原则，也无法套路收割流量。
  - 替代品因此出现：「我有一个朋友」「我的实习生」体，吃准一个灰色地带——「我二大舅的事儿你怎么证伪呢」；它比「知音体」更高阶，后者在重要篇目上尚基于公开事件，「新知音体」则解掉了最后的底线。
  - 最终结果：非虚构的批判性、公共性、真实性甚至文学性都被聪明地消解，只剩爽文的外衣。而没人愿意承认，因为「虚构只能被人消费，非虚构才能消费别人」。

  - 五个递进版本：新闻只写「车祸中保安救人身亡」；跟踪报道补身份、年龄与获救者反应；深度报道补该路口半年内第五起车祸、居民反映视觉盲区未获回应、涉事品牌曾陷召回门；人物特稿写他当天几点出门、做了什么、最后死于救援，折射底层人性；非虚构则从老张58年人生写起——喝茶转三圈杯子说能辟邪、胆小、文革失学、做生意失败、幼子病逝、为治病误入传销、病退当保安，最后才写他救人而死。
  - 分野：新闻写作是功能性的，遵循作者与读者的默契——「以最便于阅读的方式写作，使我能第一时间知道需要知道的真实的东西」，在新闻里玩花样会伤害这个功能。
  - 非虚构是艺术性的：取材生活，不必按固定模式呈现。新闻里老张之死是事件，其他内容围绕事件；非虚构里老张是时间长河的叠影，写作者可选任一时间段切入切出，甚至写尽一生，只在结尾交代他救人身亡。
  - 三个比喻：记者像车珠子的，把珠子车圆、打洞、串成手串，什么玉都成珠子造型，只是质量不同；非虚构作者像玉雕师，依玉的质地纹路下刀，但只能从已有玉石入手，切除、打磨、抛光，不能填坑洞，也不能把两块玉连起来——玉是事实，事实是底线；小说家像雕塑家，可肆意改变材料。三者没有高下之分。
  - 唯一令人讨厌的，是顶着非虚构之名行小说家之实，像玉雕师傅卖你一颗七层玲珑球，回家才发现是两半用胶水粘的。
  - 反驳「只要合情合理、能反映社会现实就是好文章」：社会现实是大量真实记录堆积沉淀而成，不该有造假藏身之地；小说家尽可写现实主义题材，但不该鼓吹自己的作品是非虚构。真实本身有价值——只有确实发生过的事才值得关注并吸取教训；《寒门状元之死》作者都号称写「真实故事」，若一开始宣称是小说，绝不可能有如此影响力。
  - 难度也来自真实：玲珑球必须一体雕刻、不能有接缝，所以需数月数年；若允许接缝，两个半球分别雕，几天就能完成且花纹更精细——但那样的玲珑球会有人要吗。
  - 体裁不是割裂的：报告文学、通讯、非虚构写作是一个连续谱系，因功能区别处于不同位置。
  - 真实有层次：世上只有「事实真实」，但除上帝外无人能达成，新闻真实只能尽量贴近。围绕主旨越近的内容，真实要求越高、失真的后果越重；偏离主旨的未必需要精确。老张怎么救人、说了什么、爆炸如何发生必须准确，他早上吃的大饼是甜是咸不必细写。
  - 但涉及人物成因不能让：不能为解释老张「爱管闲事」的性格，就捏造他父亲曾被批斗、幸得好心人庇护——即使合理、即使他同学也有类似遭遇，也不行。
  - 文末思考题：记者称老张车祸前多次经过该路口、因赌博欠债、同乡半年前见义勇为获过奖金、当天路面结冰行人稀少他却在路口徘徊、他烟瘾大且当时叼着烟、邻居几天前请他搬重物他以肩周炎拒绝。这些都有过硬人证和监控，但记者没直接说他「自私、为奖金救人、烟头引爆了车」。
  - 作者的答案：不要管这些信息。它们是对动机的揣测，非虚构不应也无法还原一个死者的动机。你一旦开始想「怎么替老张反驳」就已经输了——拿出病历证明肩周炎，对方仍能拿只有相关性没有因果性的「证据」继续质疑。正确结论是：老张的行为是高尚的，且没有直接证据证明他的卑劣。
  - 顺带点出同类手法：某微博大V在女孩烧烤被毁容事件里皮里阳秋地补一句「这姑娘平时喜欢用陌陌」，并不明说，却把无关信息塞进读者脑子。

  - 先定规范再动页面：字体用微软雅黑配 Arial，几乎所有 Windows 电脑都自带，防止换机丢字体；主题色直接挑 PPT 内置主题（他选了与课本相近的绿色）；课件播放条件差，受设备和光线影响，用浅色背景，再叠一层淡渐变避免单调；用参考线划出标题区与正文区，保证整套统一。
  - 封面页问题：背景图与课件无关、书法标题字距太大显得松散、英文副标题与标题无联系、主副标题居中而演讲人姓名在右侧。稳妥做法有二：一是去京东或当当搜书封下载图片，插入后文字左对齐；二是换成与书相关的人物图片。两者都要注意书籍朝向和人物视线指向页面内部。页面单调可用色块加层次。
  - 内容框架页问题：颜色太多导致重点不突出、衬底色块的渐变显老气、文字有多种对齐方式显杂乱。改法是先去掉复杂效果、提炼文字、统一成一种对齐，再用色块区分主次，进一步把左侧主标题换成书籍图片，最后加平滑动画与封面建立视觉联系。
  - 逻辑图问题：内容太靠上、下方太空，箭头样式不美观。按主题色换箭头，再给文字加形状衬底填补空白。
  - 选择题页问题：内容靠上、栏宽太长不宜阅读、行距太窄没有呼吸感。先加大行距、缩短栏宽、把选项换行；选项字母换成特殊英文字体 Facon 增加设计感；加色块丰富页面；版式也可从上下布局改成左右布局；考虑老师要公布答案，可加动画。
  - 总结页问题：讲马克思主义的 6 个特征，行距小、栏宽长、全是文字更像 Word。6 个并列内容适合「中心环绕排版法」，先画版式再填文字，觉得单调就加线条修饰，最后配小图标。
  - 切换效果：这套课件加了很多不必要的页面切换，过于复杂的效果对学生只是视觉负担，一般情况下淡入淡出就够。结论是教学 PPT 不必用特殊技法，页面干净整齐即可。
  - 多页共有的毛病是内容太靠上、下方留白过多，以及栏宽过长、行距过窄；改法都是先调文字（间距、栏宽、换行），再补视觉元素（色块、衬底、线条、图标）。
  【原文摘录】

  大概是多数大学老师认为 PPT 只是一种形式（毕竟二十年前也不流行用PPT上课），而老一辈搞科研的人更加注重内容罢了。

  - 一句话概括：不把两者当同类软件比较，而是用「笔记本」和「便签盒」两个比喻推出结构差异，再落到各自适用场合、OneNote 的组织手法与独有功能，最后逐条回答提问者的疑问。
  【方法/论点要点】
  - 核心判断：二选一本身就问错了。OneNote 与 Evernote 是不同类型的软件，比较长短不如分清场合，然后各用各的，或者结合使用。
  - 结构差异用四个结论串起来。OneNote 是笔记本，内部有笔记本、分区、页、子页，子页还能多层嵌套，整体是树形；Evernote 只有笔记本和页，最多三层，感官上更像两层，所以一个 Evernote 笔记本在逻辑上只等于 OneNote 的一个页。
  - 由此推出用法：笔记本可以当便签用，便签却难以胜任笔记本，所以 OneNote 适合大型、复杂、结构性的笔记，Evernote 适合轻笔记、小笔记。
  - 增长方式不同：OneNote 的总关系是树形，靠结构优化增长，各分区、各页、各子页互相链接，像一张网；Evernote 的页与页是线性关系，靠时间堆积，越久越多，彼此不交叉也不能合并成新笔记。
  - 反证很直观：如果把一本书按「一个字一页」拆开放进 OneNote，一屏只显示一个字，已经无法再优化结构，这种情况该用 Evernote；反过来把 OneNote 那种复杂树塞进 Evernote，三层根本装不下，整理完也就不想再看了。
  - OneNote 组织法之一是按书本逻辑建树。作者的例子是「日语—翻译—日汉翻译教程—第二章 论译文的审美制约机制」，四层已经超出 Evernote 的能力；同层不同书的内容再用超链接和链接便签互指，学到后面还能把初中、高中的英语笔记并进语言学笔记。
  - 组织法之二是自己造结构。政治笔记是先记课堂框架，再从各处收集答案要点填充；《综合日语教程》二十多页没有原书逻辑，靠自定顺序重排；还有难词替换词典、按从大到小排列的语法笔记、隐藏边框的表格、上题下答的双色版式。
  - 组织工具只有两个却够用。序号：第一行点按钮加标号，之后每行自动生成，还能换标号体系，作者的习惯是一、一）、1、1）、A、A）、a、a）。表格：输入字符后按 tab 就生成表格，这是 OneNote 独有；嵌套表格可以表格内再插入，也可以先做小表再套进大表，但两表结构相同时会被合并格式，需要把承载表格的那一行改成三行、把光标移到第二行才能嵌进去。
  - 独有功能一，标记生成索引：正文里打标记，点查找标记就生成一页汇总，按门类排好，适合把期末资料按重点、难点、考点标注后集中复习。
  - 独有功能二，会议笔记与 Outlook 日历相连；独有功能三，录音时把关键词写进同一个输入框，关键词前会出现播放图标，点击就跳到录音对应位置，练口语时准确率不错，但录音结束后补写的词不会被识别。
  - 独有功能四，链接引用：可以引用 Word、OneNote、PPT 和 IE 里的网页，点图标跳回原文，写论文时用来标出处；不支持 PDF。独有功能五，整段翻译走审阅里的 Bing 翻译；独有功能六，算式写到等号后回车直接出答案。
  - Evernote 一侧靠标签。标记数量有限、种类固定，标签却可以无限扩展；一篇文章可以同时贴勇敢、信念、坚强、辩证，于是想写哪个话题就把对应标签下的文章翻出来。作者的实际流程是先用 Wiz 截网页、格式化文本（图片居中、每段空两格），再导入 Evernote，批量处理靠按键精灵。
  - 对提问者几条疑问的回应：印象笔记同步快但会丢，作者三周内重置过一次；多设备 OneNote 也三端齐了；功能不如 OneNote 多，只有演示模式值得称道；附件两者都通吃；全文检索 OneNote 也有，同音词多时给词加英文引号即可；OneNote 不会被砍，Surface 的卖点就是它；他自己的 OneNote 一年半没丢过笔记，换结构的流程是先同步一台、关掉全部笔记本、再同步另一台、重组后同步、清缓存、两台重新下载。
  - 关于同步慢的原因，作者认为是 DNS 污染而非微软服务本身，给了 DNSCrypt 的旧版安装包，并说明 Win10 需以管理员身份进 CMD 运行，界面左上角显示 Protected 就通了，Linux 与 macOS 同样可用。
  - 对市场的吐槽也值得记：电子笔记设备贵、用着不便，OneNote 连语法高亮和复杂数学计算都没有，却都在做剪藏；他理想中的工具是瑞士军刀，能兼做 Office、IDE、Mathematica、操作记录仪和手写公式。
  - 一个漂亮的类比：知乎本身就是 Evernote 式管理，按问题分类、答案互不干涉，站得越久内容越多；若真有人把答案系统归类成一部百科，就必须换成 OneNote 那套先立框架再填引用的做法。

  - 一句话概括：一篇演讲整理稿，主张"知识付费"是伪命题，人们真正买的是筛选、陪伴与解读这类服务，因此出路在"门客化"而非卖课。
  【方法/论点要点】
  - 核心判断写在标题里：知识付费已死，服务付费永生。知识从来都是付费的，当下这波付费热潮买的却不是知识。
  - 用亚历山大图书馆开场：历代帝王把各地手稿抄本收进馆中，供养几十位学者，仍会面对藏书的焦虑；宋太宗编《太平总览》，每天读两三卷，留下"开卷有益"。
  - 信息爆炸的数据取自《富足》：人类从直立行走到 2003 年约创造 5 艾字节信息，2010 年每两天就有 5 艾字节，2013 年缩短到每 10 分钟。
  - 知识分类一节几乎是把教科书搬来：哈耶克的硬知识与软知识，博兰尼的显性与默性知识，野中郁次郎的显性/隐性二分，艾略特 1934 年诗句衍生出的 DIKW 模型，再加一手到四手知识。
  - 论证"知识从来付费"用的是常识性例子：孔子收腊肉作学费，陈安之卖光盘和套餐，优米网卖学生优惠卡，以及上学、读书、学奥数、学书法。
  - 但更长的历史里，知识免费才是趋势：文字少人识，摩西、佛陀、耶稣都靠口语传播；印刷术之后教育才普及，互联网之后知识才从奢侈品变成随手可得。
  - 知识不具有对抗性：专利、版权、反盗版只是法律产物，知识本身用之不竭，用的人越多，产生新知识的可能越大。TED 现场收高价、视频全部免费，就是这种结构的样本。
  - 从购买者角度看，免费是人性：朱啸虎讲投行朋友为十块钱补贴去绑卡；某付费平台的付费用户只占总用户 1%。
  - 焦虑才是最好卖的商品：朋友圈攀比、别人成功带来的恐惧、《经济学人》说中国中产阶级最焦虑，何伟在《寻路中国》里写中国人"没有几个人敢自夸自己的知识够用"。
  - 需求侧还有一组反差：人均阅读量常被拿来做国民性批判，但中国图书市场一半由教材、公务员考试等刚需托起；MOOC 在 2012 年被《纽约时报》研究指出，24 家平台完成学习规划的用户平均仅 7.6%。
  - 所谓知识付费，被作者还原为"上一轮微信群免费分享没人听了，现在收十块八块再听一遍"。
  - 碎片化学习被判定为伪命题，前提有两个：脑中有知识框架能吸收碎片，听完还要刻意练习。肖知兴的比喻是脑子里的图书馆，没有体系支撑的碎片"有害的概率大于有利"。
  - 付费的真实对象是服务：陈坤公众号 18 元月费、168 元年费，卖的是私房照、语音早晚安和讨论区，不是知识；视频网站会员买的是网速、无广告、提前看剧。
  - 律师 Jos Hellebrekers 的比喻最贴切：客户能在线找到砖瓦和粘结剂，却造不出一间房；能查到法条和案例，却拿不到针对自己的方案。
  - 因此碎片化时代最容易收费的是"门客化"服务：樊登讲房地产商月付三万雇两位大学老师读书给他听；罗胖片头语自称"您身边的读书人"；高晓松说自己就想当门客。
  - 门客不只是幕僚，鸡鸣狗盗、毛遂自荐、荆轲刺秦都算，关键是替雇主消化信息、提供见识。
  - "知"与"识"被区分开：高晓松说《晓说》讲的是"识"，"知"会掏空，"识"随年纪增长。为读书、商业内参、杂志翻译、财经见闻类产品，都是卖"识"。
  - 培根那句"知识就是力量"还有后半句：大多知识是拿来炫耀的。作者听《出版人》讲亨利·卢斯，联想到咪蒙，认为这类内容提供的是谈资与消遣。
  - 工具层面看好小密圈、小鹅通这类"集市"：得到像大教堂，成本高；集市谁都能摆摊，嗓门大或东西好的人自然吸引围观。
  - 打开率低被解释为冲动消费，焦虑下降、只订一个专栏后打开率会回升；作者自陈每天睡前听《伯凡·日知录》。
  - 最后落到自己的生意：故事学院做演讲设计、PPT 设计与舞台呈现的一站式服务，本身就是门客式服务，线上卖课"前途不是很大"。

  - 又举鸡汤的反面：扎克伯格夫妇住普通房子、没保安没仆人的故事广为流传，没说的是他们花三千万美元买下四座相邻房子准备拆除，只为住宅不被窥视。

  - 本地原文：[[file:原文/2026-10-28-目前为止，你总结出的最大人生经验是什么？.org][打开本地归档]]
  - 一句话概括：把人生活得累的根源归结为「向外求」——等反馈、要交代、怕评价，主张把注意力收回自己身上，用「不在乎结果与评价」换取行动力和主体性；值得收是因为它把内耗的机制讲得很具体，而不是空喊「做自己」。
  【方法/论点要点】
  - 病因：成长环境把人训练成「需要被外界评价、被环境认可的被动接受器」，做事没人夸就觉得白做。
  - 学校与社会的差别：学校里规则是死的、反馈是即时的，这套逻辑好使；到社会上就变成最大的枷锁。
  - 觉醒点：意识到没人欠你一个交代——努力不被看见、真诚被辜负、健身没变化，都是常态。
  - 解药是三个字「不在乎」：对结果冷酷、对评价冷酷、对虚无的关系冷酷，只对要做的那件事负责。
  - 主体性：不再为证明给谁看而拼命，动作才不会变形，动力来自自己而不是别人的嘴。
  - 反「等」：不等机会、不等贵人、不等万事俱备，做主动撞击世界的人。
  - 行动优先于思考：多数痛苦是想得太多做得太少，动起来问题会在过程中消解。
  - 孤独是筛选器：不再向外求之后必然有一段无人喝彩的时期，要把它当成完全属于自己的时间。
  - 价值交换：人脉是虚的，筹码是实的；把自己磨锋利，想要的东西会自己找过来。
  - 运气＝行动力的溢出；逆袭路径只有「今天比昨天强一点」的持续迭代。

  【我的想法】
  对「反馈依赖」的机制描述是全文最扎实的部分：把「学校＝即时反馈的封闭系统」和「社会＝没有裁判的荒野」对举，确实解释了为什么很多成绩好的人进入社会反而失速。但后半段的「不在乎」滑向了另一套成功学：它要求人对结果冷酷，却回避了「不在乎」在实践中很容易变成对他人感受的麻木，也回避了结构性因素——不是所有没结果的事都该归因于「你还在向外求」。真正可操作的是中间那层：把评价和做事拆开，先做完再谈反馈。至于「做掠食者」这类收尾，气势足，信息量低。
