- 本地原文：[[file:原文/2026-10-30-这7个Java项目，说不定你大学老师就会布置.org][打开本地归档]]
- 一句话概括：把大学老师最爱布置的 7 个 Java 课设列成清单，每个配上实验楼课程链接和知识点，基本是一份"课程设计选题表"。
【方法/论点要点】
- 计算器：Java Swing 界面编程 + 四则运算逻辑，是"稍微学了一点语言基础之后"老师必留的作业。
- 记事本：Swing + 文件操作 + Java IO，学完文件读写就会布置。
- 日记软件：用户注册登录 + 日记增删改查，涉及 Swing、文件与 IO 流、用 JDOM 解析 XML。
- WebSocket 网页聊天室：前端 AmazeUI、后端 Java、编辑器 UMEditor，覆盖 HTML/CSS/JS 与 WebSocket。
- 课程管理系统（对应图书管理系统）：Spring + Spring MVC + Hibernate，分"课程管理者/课程制作者"两种角色与权限。
- 人事管理系统：SSM（Spring + Spring MVC + MyBatis）+ easyUI。
- 支付平台业务流程：模拟买家付款到平台、卖家从平台提现，控制台输出，重点是 Java 线程与同步、并发与并行、进程状态。
- 作者的态度：这些项目"大学老师肯定会布置其中几个，不要怀疑"。
【原文摘录】
#+begin_quote
有天吃饭和朋友聊天，说到大学老师布置的开发项目，结果我们一干人说出来的都基本一样，入门级别的计算器啦，稍微大一点的记事本啦，然后到后面的图书管理系统啊，购物网站啊……
#+end_quote
#+begin_quote
计算器是大学老师一定会布置的！！！稍微学了一点语言基础之后，老师就会说"这周下去自己开发一个计算器吧，下次上课前交给我。"
#+end_quote
#+begin_quote
课程采用 SSM（Spring + Spring MVC + MyBatis） + easyUI 来开发一个比较简易的人事管理系统，让同学们能够通过实际项目掌握 SSM 项目的开发。
#+end_quote
#+begin_quote
以上总结的7个项目，大学老师肯定会布置其中几个，不要怀疑！！
#+end_quote
【我的想法】
选题清单在 2019 年很实用，今天更适合当"最小可交付项目"的模板：把 Swing 换成 JavaFX 或 Web 前端，把 SSM 换成 Spring Boot + MyBatis-Plus，把 JDOM 换成 Jackson。真正有价值的是难度梯度——从计算器到支付流程，正好覆盖 GUI、IO、XML/JSON、数据库、多线程五类基本功，比刷十个 CRUD 教程有用。
