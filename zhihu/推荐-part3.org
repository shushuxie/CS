  - 一句话概括：力荐一本被书名耽误的神书 DDIA《数据密集型应用系统设计》——豆瓣 9.7、Goodreads 4.72，以数据视角把分布式数据库、分区、事务、一致性共识讲透，作者认为它适合每一位后端开发、尤其 CRUD 程序员阅读。
  【方法/论点要点】
  - 口碑封神：国内外都被称为技术书籍巅峰之作；豆瓣评分 9.7（满分 10，近 90% 五星），Goodreads 评分 4.72（满分 5，近 80% 五星）。
  - 书名是被「耽误」的：单看书名会以为只为做数据处理的人准备，实际适合每一位后端开发程序员阅读，尤其适合每一位 CRUD 程序员。
  - 主题范围：分布式数据库、数据分区、事务、分布式系统；从数据模型与查询语言、数据编码，到数据复制和分区，再到事务、一致性共识，以及故障与部分失效、不可靠网络和时钟等挑战，作者都结合实例做有深度的讲解，在工业与学术之间平衡得很好。
  - 具体例子：讲快照隔离的多版本并发控制（MVCC）时，作者图解了 PostgreSQL 如何基于 MVCC 实现快照级别隔离。
  - 作者的核心判断：数据是后端系统的核心，所做的一切都围绕数据展开；现在大部分应用是数据密集型（data-intensive）而非计算密集型，系统瓶颈通常来自对数据的处理而非 CPU；数据库、消息队列、缓存等中间件可统称为数据系统（data system），它们之间的界限越来越模糊（如数据存储可当消息队列用——Redis，消息队列则带有类似数据库的持久保证——Apache Kafka）。
  - 读后「豁然开朗」：很多概念之前都听过，读后才发现「哇塞，这不是某技术的原理么」。
  - 阅读历程：作者大三首读只觉内容很干、很多地方看不懂，二读就好多了；并发现国内外很多系统设计课程、数据相关课程的内容这本书都有提到。
  - ACID 纠偏：原子性、隔离性和持久性是数据库的属性，而一致性（在 ACID 意义上）是应用程序的属性；应用可依赖数据库的原子性和隔离性来实现一致性，但并不只取决于数据库，因此字母 C 不属于 ACID。
  - 复制方案：主从复制非常流行，因为容易理解、不必担心冲突；一旦出现节点失效、网络中断或延迟抖动，多主节点和无主节点复制方案更可靠，代价则是系统的复杂性和弱一致性。
  - 配套学习：可结合 MIT 6.824 分布式系统课程（油管英文视频、B 站中文翻译合集 av91748150、中文文字版 mit-public-courses-cn-translatio.gitbook.io/mit6-824），其 Lab 非常不错。
  - 作者背景：Martin Kleppmann（马丁·科勒普曼）是剑桥大学计算机科学与技术系的研究助理和讲师，工业界与学术界大牛，参与 Automerge、Apache Avro、Apache Samza 等知名开源项目，个人博客 martin.kleppmann.com。
  - 因版权未分享 PDF，建议购买纸质书或找开源翻译版本。

  【方法/论点要点】
  - 背景：原笔记本坏了换成 MacBook Pro，两周后确定装机清单；偏编程学习兼顾娱乐办公，重点是把 Windows 习惯迁移过来并发挥 Mac 特点；推荐指数代表泛用性，不代表软件好坏。
  - Homebrew ⭐⭐⭐⭐⭐：Mac 最流行的包管理器，配置开发环境必备，相当于 winget + scoop；cask 可装 GUI 程序；采用滚动更新只提供最新版，旧版需自写 formula，不建议全局装旧版（易依赖冲突），可用 Nix 或 Docker 隔离。
  - AppLite ⭐⭐：Homebrew casks 的图形界面、AppStore 的补充，能分类浏览冷门软件；装机时有用，之后基本没用。
  - Warp ⭐⭐⭐⭐：Rust 编写的终端，GPU 加速并内置 AI；prompt 把命令行输入与输出分开（类似 Jupyter 单元格），长输出可滚动/折叠；免费每月 150 次 AI。
  - fish ⭐⭐⭐⭐：避开 zsh 复杂配置，开箱即用，内置语法高亮、自动补全、命令历史。
  - OrbStack ⭐⭐⭐⭐⭐：轻量 Docker Desktop 替代，也能跑 Linux 虚拟机并与宿主机深度文件集成，堪称「macOS Subsystem for Linux」；支持各发行版、可用 rosetta 2 跑 x86_64；终端 ~ssh orb~ 直连；后台休眠几乎不耗电。
  - Devbox ⭐⭐：基于 Nix 的开发环境管理，比 Nix 易用，几条命令即可建隔离、可复现环境。
  - CotEditor ⭐⭐⭐⭐：轻量文本编辑器，语法高亮与代码折叠，适合快速查看源码/改配置，是 Windows 上 Notepad3 的替代（VSCode 插件多了启动慢）。
  - VSCode ⭐⭐⭐⭐⭐：伟大，无须多言。
  - Raycast ⭐⭐⭐⭐⭐：应用启动器，比 Spotlight 强（启动应用、搜文件、剪贴板、词典、开网站）；文中配置示例：~Command + Shift + V~ 剪贴板历史、~Control + Command + Space~ emoji 选择器、别名 ~dw~ 查词典、~f~ 搜文件、~tr~ 谷歌翻译 QuickLink、~s~ 谷歌搜索 QuickLink。
  - Mos ⭐⭐⭐⭐⭐：拯救 macOS 鼠标体验。MiddleClick ⭐⭐⭐：三指点击映射鼠标中键。

  - 一句话概括：力荐黑格尔《精神现象学》——思想密度堪称人类史前五，国内冷门而在欧美热度高于《逻辑学》；作者既梳理其从感性到精神宗教的辩证法主线，又逐举「感性确定性」「自我实现」「事情本身」等章节的洞见，并附上自己从小读哲学到重拾此书的私人阅读史。
  【方法/论点要点】
  - 定调：「论思想深度，密度，丰富度，这书要是排不进人类史上前五你可以来打我」；推荐邓晓芒句读（B 站全 290 讲，讲到 145 讲才讲完，约 10 个学期）辅助阅读
  - 主线：从感性→知性知觉→自我意识→理性→精神和宗教，「上升发展的过程就是所谓的辩证法」；涵盖自我意识章（对马克思影响很大的主奴意识、斯多亚主义、怀疑论、哀怨意识）、理性章（形式逻辑、心理学、面相学、自我实现含享乐/理想/利己/自大狂、解释学、主体间性、康德实践理性）、精神章（伦理、法权、启蒙与教化、道德）
  - 浓缩度：「别的哲学家写一本书要说的东西他几页就给概括完了」——歌德写了 60 年的《浮士德》，其思想内核被黑格尔浓缩进「快乐与必然性」这个只有四页纸的小节；此外《唐吉珂德》《哈姆雷特》的思想也在书中出现
  - 冷门原因与可贵处：国内一说黑格尔都想到《逻辑学》，但欧美《精神现象学》热度远高于它；好处在于「用形而上学的语言来述说具体的思想潮流，世间百态，人生境遇」，几乎每一小节都能给生活带来启发
  - 感触点 1（感性确定性）：章首「感性确定性显现为一种最真实的确定性……」，随即辩证否定——感性经验不可言说，一旦说出就需借助概念、变成普遍的东西，故「当人们在现实生活中尝试说出意谓中的东西时，已经把那个东西消灭了」，语言才是更真实的；此章已深涉普遍与个别、主体与对象、直接与间接
  - 感触点 2（自我实现）：以「快乐与必然性」（浮士德式享受）、「心的规律与自大狂」（以追求全人类福祉为乐，却发现他人也有理念要实现——「以人类福祉为目标的热心肠转变为一种错乱的自负所发出的叫嚣」）、「德行与世界进程」（献身集体 vs 利己博弈，最终两者同归于尽，意识到自为存在同时就是自在存在）三节层层递进
  - 感触点 3（清晰写作）：谢林思想高度不比黑格尔低，但黑格尔影响力占上风很大程度上归功于可读性更强；「他搭建了一个螺旋上升的思想楼梯直通最顶级的精神」，读者「明确知道自己有没有读懂」
  - 感触点 4（精神性动物王国与欺骗，事情本身）：个体需行动才认识到原初本性＝萨特「存在先于本质」，但又需预先有被原初本性规定的目的＝「本质先于存在」，故必须直接行动；并深谈兴趣（内容方面）与天赋（行动方面）——这些边角洞见在概论性二手读物里看不到，正是原著魅力
  - 感触点 5（目的与概念）：原初本性作为目的是「概念」需靠行为获「实在性」，而行为也可被视作从目的到结果过渡的「概念」；作者由此理解那位更在意研究结果、而非实验过程的医学朋友——有些人目的反而是更现实的东西
  - 感触点 6（解释学）：作品发表前意识与作品统一，一旦发表就被抛入缺乏规定性的空间，「变成一个转瞬即逝的东西」；一个作品发表后有了独立生命力，作者本人想法反而不重要；黑格尔则超越此层——意识经历主体间性后折返主体性，可通过他人认识自己
  - 个人阅读史：小学自发读《道德经》《毛选》《圣经》，初中通读《西方哲学史》、买《纯粹理性批判》《小逻辑》（当时看不懂），初三沉迷物理放下，大学在室友带领下重拾；读过柏拉图、笛卡尔、康德、尼采、福科，最终对黑格尔最有共鸣；现读五分之三
  - 阅读体验与态度：「黑格尔的书真的非常非常难读，读两个小节花的时间足够我读一本其他的书了」，但每小节启发「其他书远远给不了」；把黑格尔哲学看成关于人类文化和社会的学说，绝对精神对他反而不重要；「哲学是用来被研究的而不是被崇拜的」，读哲学是与聪明人对话，最终回归自身
