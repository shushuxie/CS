  【方法/论点要点】
  - 路径一：本地音乐导入 Apple Music（Windows 10）。
  - ① 打开微软商店：按 ~Win + Q~ 搜索“商店”。
  - ② 下载 Apple Music。
  - ③ 登录 Apple ID 并更新资料库（网速慢要等一会），同步资料库；出现和手机一样的资料库就代表更新完成。

  - ② 打开想下载的 B 站视频，点扩展选“b 站下载助手”，点下载。
  - ③ 默认下载格式为 MP4，需转成 wav；找不到下载文件就按 ~Ctrl + J~ 打开下载列表。转换工具同上。

  - 一句话概括：把「练线条」拆成三个目的——构成外形、构成光影颜色、构成质感，每个目的都给出格子尺寸、间距要求和具体画法；值得收是因为它纠正了「练线条是为了画得又快又圆」的误区，真正要练的是判断与调整能力。
  【方法/论点要点】
  - 线条控制最终服务于三件事：形状、光影、质感。
  - 外形线条：直线与曲线，准备 4 个 5×5cm 格子，线距 1~2mm；眼睛别盯笔尖，要盯着两侧参考线。
  - 斜线先画中间一根作参考，再平行补两边；曲线练不同方向的椭圆，慢画、边画边判断调整。
  - 短线动手腕，超过 5cm 的长线改动手肘。
  - 光影线条：4 个 1.5×7.5cm 长条各分 5 格，用「叠加层数」或「改变疏密」两种方法做出 5 个色阶。
  - 质感四类：蓬松＝小曲线，柔软＝悠长完整的大曲线，坚硬＝规整直线或弧线，粗糙＝短小转折线。
  - 在球体上画线条要用「包裹式」贴上去，才符合朝向规律。
  - 收尾作业：4 个 4×4cm 质感方格；画树枝先画前面几棵粗树，再补中间，最后加远处细树。

  - 本地原文：[[file:原文/2026-10-27-如何在 clion 运行多个 main 函数.org][打开本地归档]]
  - 一句话概括：解决 CLion 里一个项目多个 cpp 各带 main 的编译冲突：用 CMake 的 file(GLOB) + foreach 自动为每个 cpp 生成可执行文件，新增文件后 Reload CMake Project 即可；值得收是因为它把「每写一题改一次 CMakeLists」变成全自动，还附带了子目录递归写法。
  【方法/论点要点】
  - 报错原因：一个 target 只能有一个 main，多个 cpp 直接 add_executable 会冲突。
  - 笨办法：手动为每个文件补一行 add_executable(a a.cpp)。
  - 正确做法：file(GLOB files *.cpp) 遍历，foreach 里用正则取出文件名当 target 名。
  - 新建 cpp 后按两次 Shift 输入 reload，执行 Reload CMake Project，main 旁就会出现绿色运行按钮。
  - Auto-Reload 只监听 CMakeLists.txt 的修改，新建 cpp 不会触发，别指望它。
  - 子目录：file(GLOB files test/*.cpp) 或 *.cpp */*.cpp；官方递归写法是 file(GLOB_RECURSE files *.cpp)。
  - 想在运行框显示「文件夹/文件名」，可用两级正则替换，但排序可能会乱。
  【原文摘录】
  #+begin_quote
  之前这里写了一个小程序解决这个问题，就是就是读文件名写字符串。因为 Clion 使用的是 CMAKE 来管理编译执行，所以在其中加入对应的 add_executable(a a.cpp) 即可。
  #+end_quote
  #+begin_src text
  file (GLOB files *.cpp)
  foreach (file ${files})
      string(REGEX REPLACE ".+/(.+)\\..*" "\\1" exe ${file})
      add_executable (${exe} ${file})
      message (\ \ \ \ --\ src/${exe}.cpp\ will\ be\ compiled\ to\ bin/${exe})
  endforeach ()
  #+end_src
  #+begin_quote
  在新建对应的 xx.cpp 文件之后，创建 main 函数，在项目处右击，选择 Reload CMake Project，在 main 函数旁边就会出现那个绿色的运行按钮了（快捷操作，按两次 shift，输入 reload，就会出现选项）。
  #+end_quote
  #+begin_quote
  之前尝试过 Auto-Reload CMake Project 选项，但是作者发现该选项应该是监听 CMakeLists.txt 文件修改的，在创建新的 cpp 文件后应该不会自动 reload，所以没有用这个功能。
  #+end_quote

  - 场景一：用户注册/创建商品时多点几次，数据库重复建记录。

  - 方案三 Redis SETNX：以业务唯一字段为 key，设置成功是首次，失败即已执行，记得设过期时间。
  - 其他：状态机、悲观锁、乐观锁；转账、支付这类涉及钱的接口尤其要优先考虑幂等。
  【原文摘录】
