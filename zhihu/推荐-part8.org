- 一句话概括：把日本插画师 keigo 的"动物拟人"系列讲了一遍——兔子长颈鹿鳄鱼树懒都保留动物形态却过着人的日子，冷幽默里带点丧，编辑部还顺手交代了他从印刷厂职员变成职业画师的经历。
【方法/论点要点】
- 人物背景：keigo 大学读艺术，毕业后进印刷厂做厌倦的工作，想摆脱又无力改变时开始画画，后来把插画做成出口。
- 核心手法：动物保留自己的形（长耳朵、长脖子、扁脑袋、慢动作），行为却完全是人——于是天然产生反差笑点。
- 固定 CP：兔子 + 长颈鹿（小巧 vs 高大）出场最多，鳄鱼是勤劳憨厚的运动担当，树懒是后期加入的慢速笑料。
- 情绪底色：主角多半闷闷不乐、眼神呆滞，画面却让人会心一笑，在重复的日子里补一点幽默。
- 彩蛋：keigo 怕老婆，妻子不让他停他就一直画；账号 ins:k5fuwa。

#+end_quote

事实上，keigo的画不仅戳笑点，还戳人心。无论好或不好，主角常常是闷闷不乐眼神呆滞的，表现出来的画面又能让人会心地笑，在不那么有趣的重复日子里加了点幽默意义。

【方法/论点要点】
- TranslucentTB：不到 700K、免安装，右键管理员运行后常驻任务栏；Blur 半透明、Clear 全透明、Normal 还原、Open at Boot 开机自启。
- 万彩办公大师：60 多种功能免费无广告，绿色免安装，双击 Officebox.exe；分 PDF、格式转换、图片处理、OCR、录屏、文件处理等 19 类工具，还内置上千套模板/素材/图标和办公网址；常用功能可点右上角收藏。
- 盘搜搜（pansoso.com）：专搜网盘文件，支持百度网盘、新浪网盘；失效分享多，作者建议准备几个同类站轮换。
- UPUPOO：动态桌面壁纸，开发者承诺视频不作为盈利项所以全免费，另带文件整理、追番、壁纸控制等桌面小插件；可与 TranslucentTB 配合做出"全面屏"效果。
- 网速/CPU 监控插件：11 种皮肤，设为"显示在通知栏"并隐藏主窗口，开机自启，几乎不占内存。
- 火绒安全：纯净无广告，14 项防护 + 8 个扩展工具（火绒剑、漏洞修复、右键管理、垃圾清理、文件粉碎、弹窗拦截、启动项管理、流量监控）；插件按需下载以减小体积，作者建议必装"弹窗拦截"。
- 小黄条（YYNote.exe）：500K 绿色便签，图层可嵌入桌面、界面极简，比系统便利贴好看好用。

* 你极力推荐的 Chrome 扩展有哪些？  :推荐:Chrome插件:浏览器扩展:效率工具:

- 本地原文：[[file:原文/2026-10-25-Chrome必备插件推荐.org][打开本地归档]]
- 一句话概括：PPT 设计师三顿的 16 款 Chrome 插件清单（2019 年首发 10 款 + 2020 年增补 6 款），每款都配推荐理由与截图/动图演示，末尾还附 crx 离线安装攻略——一篇就能补齐「标签页、截图、翻译、下载、去广告、资源嗅探」整套浏览器基建。
【方法/论点要点】
- Infinity New Tab：标签页美化，上半屏搜索、下半屏常用工具与网页，网页/背景/布局/字体/搜索框形状均可自定义（"不仅颜值超高、功能实用，而且自由度极高"）。
- Imagus：鼠标悬停即放大预览图片，搜索图片时同样好用，"悬停即可预览，告别一切'图片看不清'"。
- 集装箱：四合一——谷歌助手（直连谷歌系网站与应用商店）、网盘助手（百度网盘直下、自定义提取码、一键生成分享链接）、优惠购（领券 + 各站历史价格）、下载卫士（屏蔽下载站广告与无关链接）。
- Context Menus 右键搜：页面空白处右键生成当前页二维码/短网址，选中文字可搜索/翻译/生成二维码，选中图片可以图搜图、识别二维码，功能可在设置里自定义。
- OneTab Plus：一键把几十个标签聚拢成组，每次整理生成一个标签组并保留历史组，可增删、可"打开全部"还原。
- Awesome screenshot：基本截图 + 整页截图 + 录屏；截图后可调尺寸、裁剪、加文字框线箭头，支持打印与导出 PDF。
- SimpRead 简悦：自动屏蔽广告与无关信息，把网页提取重排成干净阅读页，另附划词翻译、字数统计。
- 图片下载助手：一键抓取网页中全部图片，呈现在独立页面里，可按大小、属性筛选后批量下载，专治"右键另存为不可用"。
- Adblock Plus：拦截页面广告让版面变清爽；冷门用法是用"拦截元素"隐藏丑导航条、百度搜索右侧推荐栏，方便截图出图。
- 油猴脚本（多功能工具箱）：AC-baidu（去广告 + 去掉百度跳转中间页，直连目标地址）、百度网盘直接下载助手（跳过大文件限制，链接可交迅雷等工具）、全网音乐一键免费下载、看真正想看的微博（按时间排序 + 屏蔽广告 + 改外观）、网页限制解除（解除复制限制）、豆瓣资源下载大师（右侧直出下载/在线观看/字幕，附 IMDb、烂番茄评分）、购物党比价（跨平台比价 + 历史最低价）、右键在新标签打开图片时自动取最优画质。
- SPS 搜我听歌：输入歌名即搜即放，含音量、进度条、收藏、歌词，皮肤随歌曲变化；另有搜我广播、搜我播客（可按地区找电台）。
- Graphitabs：一键把打开的标签整理成思维导图，同站标签自动归组，可拖拽缩放、可隐藏页面；作者评价"没有任何花里胡哨的功能"，适合临时整理标签。
- 沙拉查词：聚合多词典的划词翻译，支持 PDF 内划词；带单词本（记录生词来源与上下文），可设查词快捷键、切换纯翻译/学术等情景模式。
- 微信公众号同步助手：把文章一键分发到头条、知乎等平台，同步时自动重传图片；作者提醒有页面错位等 BUG，建议平时关闭、需要同步时再开。
- IE Tab：在 Chrome 内访问只支持 IE 内核的企业网银、政府系统，可自选 IE 版本，不必另装 IE。
- Download+：下载管理（按钮里搜索/删除/暂停）+ 资源嗅探（分析网页图片与音视频并批量下载）。
- 离线安装：从 crx4chrome.com、chromecj.com 下载 crx；方法一是在"设置-更多工具-扩展程序"里把 crx 直接拖入；方法二是把 crx 后缀改成 rar/zip 解压，勾选开发者模式后"加载已解压的扩展程序"；报错则把 ~_metadata~ 文件夹改名为 ~metadata~。
