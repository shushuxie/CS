  - 一句话概括：以「你还没到读这本书的阶段」立论，判定 CSAPP 适合谁、不适合谁，再给出从 CS50 到数据结构的入门路线——讲的是「何时读哪本」，而不是又列一遍经典。
  【方法/论点要点】
  - 前提是一句反常识判断：书单读不下去未必是书不好，而是「现阶段的你，还不适合看这本书」，同一本书要在对的时间读。
  - CSAPP 的定位：从主机部件、CPU/内存/硬盘怎么连接讲起，讲到程序如何被编译、链接成汇编码再变成机器码执行，还覆盖网络、组成原理、进程与线程，从硬件讲到软件。它的用处是照出知识缺口，适合喜欢刨根问底的人。
  - 门槛在语言：全书以大量 C 程序为例，默认读者已会 C 或 Java；作者自己大二买第二版、次年买第三版，断断续续读了好几年仍未读完。
  - 所以先修哈佛 CS50：共 20 集，一天一集 20 天看完，是 CSAPP 内容的精简版且对新手友好。
  - 五项清单与顺序：CS50 → C Primer Plus → CSAPP 第三版 → C++ Primer → 邓俊辉《数据结构》（配免费视频，讲 Vector 扩容等模板底层实现，面试题富矿，但对新手不友好）；不必看完一本再开下一本，因为那样「很有难度」。

  【我的想法】
  书单里的五项都是常见经典，真正值钱的是「书单要匹配阶段」这个提醒，以及敢把豆瓣 9.9 分的书明确标成非入门书。局限也清楚：说「两门课、三本书」却列了五项，前后对不上；更关键的是没给出判断「自己是否已到这一阶段」的标准，读者仍只能靠试读来试错。
