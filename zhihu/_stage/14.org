- 一句话概括：用 Office 365/2016 开发者预览版的"3D 模型导入 + 平滑切换"做发布会级 3D 演示：找模型 → 导入 PPT → 复制一页改大小/加文字 → 加"平滑"切换。
【方法/论点要点】
- 前置：把 Office 更新到最新的开发者预览版（Office Insider）。
- 支持的模型格式：fbx / obj / 3mf / ply / stl / glb。
- 找模型的三种途径：① 微软自家的 Paint 3D，操作简单适合新手，可直接导出 fbx 或 3mf；② 免费 3D 模型站——archive3d.net、sccnn.com、top3dmodels.com、dmi-3d.net、scifi3d.com、model3d.biz；③ 用 Cinema 4D / 3ds Max / Rhino 自己建模（门槛较高）。
- 导入：更新后"插入"选项卡里出现"3D 模型"，选兼容格式文件导入。
- 摆姿势：单击模型中央出现旋转按钮，拖动鼠标即可任意旋转。
- 做动画：把这一页复制一份，在第二页调整模型大小、可加文字，然后给第二页加切换效果"平滑"——播放时就是模型连续放大/转场的 3D 效果。
- 局限：当时 3D 功能刚起步，支持格式还不够丰富。

【我的想法】
核心不是 3D 模型本身，而是"复制页面 + 平滑切换"这个技巧——同样的手法也能做 2D 元素的连续位移、缩放，不依赖 3D 也能出效果。文中"开发者预览版"的说法已过时：3D 模型与平滑切换在 Microsoft 365 正式版里早已可用，模型也能直接从 Remix 3D/在线库插入，不必再折腾 Insider。真要做产品演示，3D 模型更适合"一个主体缓慢旋转"，一页塞多个会明显掉帧。
