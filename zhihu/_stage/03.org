  - 一句话概括：19 届本科生总结的 Java 后端自学路线与书单，覆盖基础、Web、进阶和加分项，可当校招复习地图。
  【方法/论点要点】
  - 总原则：校招“拿不出像样的项目没关系，但是基础万万不可不牢固”；语言只是工具，面试看基础与解题思路。
  - 基础：读《Java核心技术 卷1》，跳过图形、Swing 等章节，吃力可略过多线程；用 Java 写实验并刻意套设计模式，之后速读查漏。
  - JavaWeb：学 Servlet/JSP、Tomcat、MVC、MySQL 与 JDBC、HTTP，参考《Head First Servlets and JSP》和 how2j；重点 Servlet 生命周期，做含注册登录、增删改查的小网站并部署上云。
  - 进阶：读《Java编程思想》（跳过 GUI 章），写 HTTP 服务器、聊天室或 DBMS 级项目；读《Effective Java》；再攻多线程与 JVM，看《Java并发编程的艺术》《深入理解Java虚拟机》，抓内存模型、锁和 GC。
  - Web 进阶：Linux（TLCL 加学生服务器）、操作系统、数据库（《MySQL必知必会》）、网络（《图解HTTP》）、LeetCode、SSM（重点 IOC 与 DI，别依赖框架）。
  - 加分项：前端、一门动态语言、大数据，以及 Dubbo、Redis、Nginx、Docker 等工具。
