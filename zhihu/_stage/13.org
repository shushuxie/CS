- 一句话概括：把 Win 键相关的十来组常用快捷键按场景串了一遍——从操作中心、设置、资源管理器到云剪贴板、截图、Emoji 和虚拟桌面，目标是少碰鼠标。
【方法/论点要点】
- ~Win+A~：打开操作中心（通知栏），通知与常用设置开关都在这里。
- ~Win+I~：直接打开"设置"应用。
- ~Win+E~：任何界面下唤起文件资源管理器。
- ~Win+S~：唤起独立的 Windows 搜索（1809 后与小娜分离）。
- ~Win+K~："连接"快速操作，专门用来连蓝牙音响、鼠标、无线键盘与无线显示器，省掉层层进设置。
- ~Win+D~ 显示/最小化全部窗口回桌面；~Win+,~（逗号）是"预览桌面"，临时看桌面文件又不影响当前窗口。
- ~Win+L~：锁屏，五分钟内不休眠，短时离开既保住工作状态又不泄露信息。
- ~Win+V~：唤出云剪贴板（1809 新增），能看本机历史、跨 Windows 设备同步，"在家复制、办公室粘贴"。
- ~Win+Shift+S~：原生截图，可矩形/全屏/任意形状，1809 起还支持截屏标注。
- ~Win+;~：调出 Emoji、颜文字与符号输入框。
- 虚拟桌面：~Win+Ctrl+D~ 新建、~Win+Ctrl+F4~ 关闭当前、~Win+Ctrl+←/→~ 左右切换。
- 进阶：官方快捷键全集见微软支持文档；要自定义全局快捷键可用 AutoHotkey（脚本语言，需一点编程基础）。
【原文摘录】
#+begin_quote
大多数 Windows 10 默认的快捷键都是和 Windows 徽标键相绑定的，几乎所有字母、数字按键和 Win 徽标键都有快捷键绑定。
#+end_quote
#+begin_quote
Win + L 锁定屏幕的快捷键是我日常使用频率第二高的快捷键。利用这个快捷键我可以快速锁定屏幕，进入登录界面，同时五分钟之内又不会休眠。
#+end_quote
#+begin_quote
云剪贴板是 Windows 10 1809 中新加入的功能。除了能够保存本机的剪贴板历史记录，Windows 10 的云剪贴板还可以在多个 Windows 设备之间同步你的剪贴板内容，真正实现「在家复制，在办公室粘贴」。
#+end_quote
#+begin_quote
如果你对上面介绍的快捷键也不太满意，希望能够自定义自己的快捷键，我们也可以通过 AutoHotKey 来自定义 Windows 上面的全局快捷键。
#+end_quote
【我的想法】
Win 键系快捷键里性价比最高的四个是 ~Win+E~、~Win+D~、~Win+Shift+S~、~Win+V~，其余属于"知道就好"。文章写于 1809 时期，需要注意：~Win+V~ 要先在设置里手动开启剪贴板历史，且同步依赖微软账户；~Win+;~ 在部分输入法下会被占用。虚拟桌面那组很适合"工作/娱乐分开"，但很多人装了 PowerToys 后用 FancyZones 反而更顺手。
