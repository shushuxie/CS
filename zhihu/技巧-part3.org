  - 一句话概括：把社交焦虑重新定义成“协作分工”的思维练习——除原生家庭外，别人找你都只为完成他自己的事、你只是其中一环，于是不必怕被评价，只需想清楚如何高效配合、顺便分一杯羹。
  【方法/论点要点】
  - 第一步是换思维：除原生家庭外认识的人，与你交往都是为了完成他们自己的事情，而这件事正好需要你配合，你是这个事里的一环。
  - 由此消解被评价的恐惧：“别人只是在完成他们自己的任务，没有时间对你投入过多的关注，很多时候都是自卑的人自己的投射。”
  - 结果归因要理性：配合得好对方就满意；对方不满意也多是没有配合好这件事，回头“慢慢梳理这个事情里的权责，分析下到底是谁的问题”；只要下次配合好，“对方基本不会记得上次的事情”。
  - 实战动作：别人来找你，就先想“对方现在需要你配合做什么事情”，再想“如何高效的和对方配合好，且自己也能分到一杯羹”。
  - 例外处理：若有人你什么都没做就打压你，那说明“这些人不是做事的人”，直接远离即可。
  - 收尾心态：按流程走会发现“别人都是大白菜，我们自己也是大白菜”，练多了自然不扭捏。

  - 一句话概括：刻意训练的第一条思维就是“永远不在谈话中自贬”——你怎么说自己，就会怎么看自己，别人也据此看你；示弱换不来同情，只会招来欺负，所以要多夸自己、凡事看到好的一面。
  【方法/论点要点】
  - 训练的核心动作：“永远不在谈话中自贬”，作者把它类比为一种极为严重的破窗效应。
  - 具体禁令：不说自己身体不好、长得不行、脑子不行、能力不行。
  - 心理机制：久而久之就会真信了，变自信爱自己会很难；而且“你怎样说自己，你就会怎样看自己，别人也会怎样看你”“外界对你的评价态度就取决于你如何评价自己”。
  - 现实后果：职场里示弱自贬不会换来可怜，反而会被用各种显性隐性手段欺负，要么穿小鞋要么被孤立，“自贬不会让你的生活变好，反而是生活悲剧的开始”。
  - 人性解释：人见不得身边人比自己过得好，不认识的人倒霉出糗别人第一反应是哈哈大笑，所以“自贬是一种精神艾滋病”，亮出脆弱等于请人吸食你的能量。
  - 收尾导向：困难不会因示弱而减少，“凡事从好的一面去看，凡事发生必有利于我”，多夸自己生活会巨变。

  - 本地原文：[[file:原文/2026-10-19-MacbookPro的中英文输入法切换键CapsLock延迟卡顿如何解决-1931684461034075608.org][打开本地归档]]
  - 一句话概括：一条命令关掉 macOS 隐藏的 Caps Lock 延迟属性，不用装任何第三方工具就能消除中英文切换的卡顿感，重启后把命令写进 shell 启动脚本即可长期生效。
  【方法/论点要点】
  - 原理：macOS 自带一个隐藏的 HID 属性，专门控制 Caps Lock 的按键延迟，把它设为 0 就等于彻底取消延迟。
  - 立即生效的做法：打开“终端”，直接执行下面这一行，无需 sudo、无需重启：
  #+begin_src bash
  hidutil property --set '{"CapsLockDelayOverride":0}'
  #+end_src
  - 开机自动应用：重启后该设置会失效，需要把同一条命令加入 shell 启动脚本，例如 =~/.zshrc= 或 =~/.bash_profile=。
  - 避坑提醒：不要用“慢速键”来解决，开启后删除和光标移动都会变得很慢，得不偿失。
  - 备选方案：作者同时附了一个开源小工具 CapsLockNoDelay（GitHub：gkpln3/CapsLockNoDelay），不想改脚本的人可以用它。
  【原文摘录】

  - 一句话概括：把“怂”归因于杏仁核把社交场合误判成野兽攻击，而非性格缺陷，然后给出一整套立刻能做的身体锚定、话术、呼吸、对视、低风险暴露与复盘练习，靠骗身体先动起来重建自信。
  【方法/论点要点】
  - 原理：大脑的警报器杏仁核一觉得危险就让你躲，但它还活在原始社会，把同事的眼神、老板的脸色当成野兽攻击——想躲是警报误报，不是性格问题。
  - 招一，两分钟高能量姿势：每天在没人的地方站直，双手叉腰、抬头挺胸，用肚子发力念“我能掌控局面”；研究显示能增加自信激素、减少压力激素。有来访者在楼梯间练一周，开会声音大了三倍。
  - 招二，生理锚定止颤：说话前舌头死死顶住上牙膛，身体绷住声音就不抖；打电话前先顶住舌头说三遍“喂喂喂”。
  - 招三，应对欺负的回应公式：疑问句 + 重复对方的话 + 平静表情。同事推活就说“你的意思是让我帮你完成报表对吗？”，对方八成会慌；语速学树懒，越慢越有力量。
  - 招四，不敢对视的取巧法：看对方眉心或鼻梁，对方会以为你在直视；开会时轮流看每个人眉心三角区，练熟后再慢慢移到眼睛，三个月能自然对视。
  - 招五，4-7-8 呼吸：吸气四秒、停七秒、吐气八秒，每天练五次、坚持两周，心跳快时也能稳住声音；地铁被挤时用这招能忍住不躲。
  - 招六，睡前写三条“今天我比XXX强”，例如“比老板多喝了两杯水”“比同事多眨了一次眼”；大脑是复读机，听一个月就会当真。
  - 招七，零风险暴露练习：去便利店说“不用塑料袋”，去奶茶店说“去冰五分糖”，身体习惯不发抖，大脑才会相信“说话不会死”。
  - 招八，退缩后复盘：用手机录音，以1.2倍速听自己刚说的话，会发现实际声音比以为的大，听十遍以上尴尬会变搞笑，即脱敏疗法。
  - 招九，破“准备陷阱”：开会前在大腿写个“3”，只给三秒考虑，数到三必须举手，不给大脑反悔时间，五次后形成条件反射。
  - 招十，破除被围观的幻觉：明天穿两只不同颜色的袜子，根本没人发现；记住 95% 的人五分钟后忘记你说的话，99% 的评价是他们对自己的不满投射。
  - 招十一，每天 1% 进步：今天多和外卖小哥说谢谢，明天多问一句“能不能打折”，半年脱胎换骨；把尝试当实验，输了收集数据，赢了就是赚到。
  - 终极大招：把自己当游戏角色养，被老板骂是刷 BOSS，搭讪是解锁新地图，汇报是打团战，心理距离一拉开行动就变容易。
  - 收尾要求：不需要变成社牛，只要做到不躲不退；当下就站起来挺直腰板，对窗户喊一声“收到”。
