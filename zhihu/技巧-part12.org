  - 本地原文：[[file:原文/2026-10-30-MarkDown的10条常用语法.org][打开本地归档]]
  - 一句话概括：用一页篇幅把 Markdown 最常用的十类语法（标题、分割线、列表、链接、引用、代码、粗斜体、图片、表格、自动转换）连同容易踩的坑一起讲完，适合当速查表而不是教程。
  【方法/论点要点】
  - 标题：用 ~#~ 标示，共六级，~# 内容~ 与 ~# 内容 #~ 等价；后者因为标明了收尾位置在某些场合更易读。
  - 分割线：连续三个及以上的 ~-~ 或 ~*~。
  - 列表：无序用 ~* ~、~+ ~、~- ~ 开头；有序用"数字. 空格"，且数字本身不参与排序，随便写都会自动编号。
  - 超链接：常用 ~[链接地址][描述]~ 形式（另有一种是行内括号写法）。
  - 引用：用 ~>~ 标示；**引用块内单个回车不会换行，只会插入一个空格，要换行必须敲两个回车**。
  - 代码：段内用成对反引号包裹；整段代码用缩进（原文说"两个制表符"）或围栏。
  - 粗体斜体：1 个 ~*~ 斜体、2 个 ~*~ 粗体、3 个 ~*~ 粗斜体。
  - 图片：~![图片地址 "替代文本"]~；替代文本即 HTML 的 alt 属性；Markdown 本身**无法指定图片大小**，要调尺寸得用 ~<img>~ 标签。
  - 表格：~|~ 分列，一行文本即一行，表头与表体之间用三个以上 ~-~ 分隔，在 ~-~ 两端加 ~:~ 控制对齐（不加=左对齐，两边都加=居中，只在尾部加=右对齐）；单元格内换行用 ~<br/>~；每行列数可以少于总列数。
  - 自动转换：~<可识别内容>~ 会被自动识别为链接等；识别不了 ~<~、~&~、~.~、引号时用反斜杠转义。
  - 换行兜底：换不了行就多敲几次回车，或直接上 ~<br/>~。
  【原文摘录】
  #+begin_quote
  Markdown语法和Html语法有一定的相似性，比如对于标题的定义，不论是Markdown还是Html都分了6级。不同的是Markdown是使用#号来进行标示。
  #+end_quote
  #+begin_quote
  不过在引用段落内，一个回车符并不能让文本内容按照期望换行，仅仅只是加入了一个空格字符而已。如果需要让文本内容换行，那么需要输入两个回车符。
  #+end_quote
  #+begin_quote
  仅仅使用两个制表符，就可以完成代码的插入。如果是再行内插入代码，则使用成对出现的反引号表示代码。
  #+end_quote
  #+begin_quote
  目前 Markdown 语法暂时无法定于图片大小，如果需要定于图片大小，可以使用 HTML 语言中的 <img> 标签。
  #+end_quote
  #+begin_quote
  在单元格内换行，可以使用<br/>进行换行操作。每一行的列数允许少于总列数。
  #+end_quote
  【我的想法】
  这类速查表的价值在"边界条件"：引用块里单回车不换行、图片不能调大小、表格靠 ~:~ 对齐——这些恰恰是初学者反复搜的。代码块那句"两个制表符"其实是早期实现细节，现在统一用三反引号围栏更稳，读的时候要能分辨哪条是语法、哪条只是当年的编辑器习惯。

  - 一句话概括：把 Windows 命令提示符里真正用得上的十几个命令（磁盘检查、批量改名、系统文件修复、查找字符串、定时关机、查蹭网、杀进程、比文件）连同各自的参数和用途串成一份可查清单，末尾附窗口技巧、快捷键与一段彩蛋脚本。
  【方法/论点要点】
  - 背景：cmd.exe 是为兼容 DOS 命令行的优点（安全、高效、指令传输快）而保留的，部分命令需要管理员权限。
  - ~tree 目录 /f~：分支形式列出目录下全部子目录和文件；去掉 ~/f~ 只显示文件夹；输出太长接 ~|more~ 分页；要存档就重定向 ~tree 目录 /f >d:\1.txt~。
  - ~chkdsk /f~ 检查并修复磁盘错误，~/r~ 查坏扇区并恢复可读信息，~chkdsk 盘符~ 指定盘；也能修"U 盘文件或目录损坏且无法读取"（代价是错误项可能被删除）。
  - ~ren 旧.txt 新.txt~：改名，可带路径；配合通配符 ~*~（任意多字符）和 ~?~（任意一个字符）批量改，如 ~ren d:\12?.txt 34?.txt~。
  - ~sfc /SCANNOW~：扫描所有受保护系统文件的完整性，并用正确的微软版本替换损坏者。
  - ~IExpress~：微软自带的小工具，用来做 CAB 压缩包和自解压安装包。
  - ~findstr "abcd" 1.txt~：在文件里查找字符串，相当于 Windows 版 grep。
  - ~shutdown /s /t 233~：233 秒后关机；~shutdown /a~ 取消定时关机计划。
  - ~arp -a~：查看同一网段设备的物理地址，可用来判断有没有人蹭网。
  - ~taskkill /f /im notepad.exe~：按进程名强杀；先 ~tasklist~ 看 PID，再 ~taskkill /pid 4708~。
  - ~fc~：比较两个文件差异；~attrib +r 1.txt~ 改文件属性（如置只读）。
  - 网络排查三连：~ipconfig /all~ 看网卡、MAC、DNS、本机 IP；~ping 127.0.0.1~ 验证本机 TCP/IP 栈；再 ping 本机 IP、网关、远程地址，逐层定位是配置错、硬件问题还是外网不通。
  - 直接唤起系统工具：~calc~ 计算器、~mspaint~ 画图、~magnify~ 放大镜、~osk~ 屏幕键盘、~notepad/write~、~charmap~ 字符映射、~mstsc~ 远程桌面、~services.msc~ 服务、~devmgmt~ 设备管理器、~diskmgmt~ 磁盘管理、~msinfo32~、~msconfig~、~dxdiag~、~eventvwr~、~regedt32~、~resmon~、~perfmon~、~compmgmt~。
  - 窗口技巧：标题栏右键 → 属性，勾选"快速编辑模式"即可选中复制；同处可改字体、颜色、缓冲区；~title 标题~ 改窗口标题，~color 前景 背景~ 改配色（0 黑 1 蓝 2 绿 … F 亮白）。
  - 快捷键：~F7~ 命令历史列表、~F8~ 循环搜索历史、~F3~ 重复上一条、~Tab~ 补全当前目录文件名（~Shift+Tab~ 反向）、~Ctrl+C~ 中止、~Alt+F7~ 清空历史、~Alt+PrintScreen~ 截当前窗口。

  DOS系统是命令行界面，比起易于操作的图形界面的Windows系统有着安全、效率高、指令传输快的优点。早期版本的Windows系统是以DOS系统为核心的。
  #+end_quote
  #+begin_quote
  chkdsk即check disk，是用来检测磁盘文件系统错误的命令，它可以列出并纠正磁盘上的错误。由于它对错误的处理方式只有删除，所以有可能使数据丢失。
  #+end_quote
  #+begin_quote
  sfc命令会扫描所有保护的系统文件的完整性，并使用正确的 Microsoft 版本替换不正确的版本。
  #+end_quote
  #+begin_quote
  arp -a 可以查看同一网络下的设备的物理地址，可以用来查看是否有人蹭网。
  #+end_quote
  #+begin_quote
  ping 127.0.0.1 如发现本地址无法ping通，就表明本地机TCP/IP协议不能正常工作。
  #+end_quote
  【我的想法】
  现在多数人日常用 PowerShell，但这批命令仍然兼容且更短。真正值得背下来的是三类：排障（ping 三层递进、ipconfig /all、arp -a）、批量（ren + 通配符、findstr、tree 重定向）、救急（chkdsk、sfc、taskkill）。至于 ~color 0a~ 的数字雨，属于"知道就好"，它跑起来会占满 CPU。

  - 本地原文：[[file:原文/2026-10-30-45个值得收藏的 CSS 形状.org][打开本地归档]]
  - 一句话概括：45 个用纯 CSS 画出来的图形（正方到锁头），每个都给完整代码，核心手法只有三个——边框拼三角、伪元素叠加、transform 旋转斜切；现在多半不直接用，但拆解思路很值钱。
  【方法/论点要点】
  - 基础形状靠盒模型：宽高 + ~background~ 得到矩形；加 ~border-radius: 50%~ 变圆；加 ~border-radius: 100px / 50px~ 变椭圆。
  - 三角形的原理：宽高设为 0，用三条透明边框 + 一条实色边框拼出来。如向上三角 ~border-left/right: 50px solid transparent; border-bottom: 100px solid red~；向下就把实色边框换成 ~border-top~；左右同理换方向。
  - 直角三角（左上/右上/左下/右下）：只留两条相邻边框有颜色、另两条透明，靠边框的斜接（miter）天然切出 45° 斜边。
  - 伪元素扩展能力：~::before~ / ~::after~ 相当于凭空多两个形状，配合 ~position: absolute~ 叠在原元素上，再用 ~transform~ 旋转/斜切/位移，就能从"一个 div"长出复杂图形。
  - 典型组合：六角星 = 正三角 + 倒三角（~:after~ 画倒三角，~top: 30px~ 错位）；五角星 = 一个三角形旋转 35°，两个伪元素再各自旋转叠加；爱心 = 两个圆角方块旋转 45° 再拼合；月亮 = 一个圆 + 一个偏移的同心圆做遮罩（~box-shadow~ 挖空）；吃豆人 = 圆加两个三角形做"嘴"。
  - 其它可用手段：~transform: skew(20deg)~ 做平行四边形、~border~ 配合 ~clip-path~ 做多边形（五/六/八边形）、多段 ~box-shadow~ 做丝带与徽章、~border-radius~ 的四角独立值做鸡蛋/对话泡泡。
  - 工程建议：现在图标首选字体图标或 SVG，纯 CSS 图形的价值在于"理解定位、伪元素、边框、变换的组合方式"。
  【原文摘录】
  #+begin_quote
  CSS能够生成各种形状。正方形和矩形很容易，因为它们是 web 的自然形状。添加宽度和高度，就得到了所需的精确大小的矩形。添加边框半径，你就可以把这个形状变成圆形，足够多的边框半径，你就可以把这些矩形变成圆形和椭圆形。
  #+end_quote
  #+begin_quote
  我们还可以使用 CSS 伪元素中的 ::before 和 ::after，这为我们提供了向原始元素添加另外两个形状的可能性。
  #+end_quote
  #+begin_quote
  虽然我们现在大都使用字体图标或者svg图片，似乎使用 CSS 来做图标意义不是很大，但怎么实现这些图标用到的一些技巧及思路是很值得我们的学习。
  #+end_quote
  #+begin_quote
  #triangle-up { width: 0; height: 0; border-left: 50px solid transparent; border-right: 50px solid transparent; border-bottom: 100px solid red; }
  #+end_quote
  【我的想法】
  这组代码最好的用法不是抄，而是当"CSS 渲染模型"的练习册：三角形让你真正搞懂 border 是两个梯形拼出来的；星形和爱心让你体会伪元素的"图层"概念。真实项目里我会直接用 SVG，但在需要极小体积、随文字颜色变化的装饰元素（角标、箭头、气泡尾巴）时，border 三角仍然是零资源的首选。

  - 一句话概括：读 Spring、Dubbo 这类框架源码时，靠三个动作就够：~Ctrl+T~ 从接口/模板方法跳到实现、~Ctrl+Alt+H~ 看调用层级摸清链路、Debug 里用 F5/F6/F7/F8 有节奏地跟，而不是一行行走。
  【方法/论点要点】
  - Quick Type Hierarchy（~Ctrl+T~）：不只看类继承，更重要的是在**方法上按**，直接列出实现类——从 BeanFactory 的接口方法 ~getBean()~ 一步跳到真正的实现，特别适合模板方法模式（抽象类里定义模板，~Ctrl+T~ 找实现类）。
  - 想看更完整的层级用 Open Type Hierarchy，左侧 Type View 展示更清楚。
  - Open Call Hierarchy（~Ctrl+Alt+H~）：作者认为这是读源码最有用的利器——能看到方法的调用关系树，直接定位到所有调用点，"可以轻松游走于各种方法调用之间"，但身边很多人不知道它存在。
  - Debug 四个键先记牢：~F5~ Step Into 进方法；~F6~ Step Over 逐行过；~F7~ Step Return 跳出当前方法；~F8~ Resume 跑到下一个断点。
  - 典型陷阱：想进 ~ClassPathXmlApplicationContext~ 构造函数，F5 却掉进 ~loadClass~（类加载）。这通常说明该类是第一次加载——直接 F7 跳出，回到原行再 F5，这次才真正进入构造函数。
  - 跟踪节奏：以"先找到整体脉络"为准，不要每行都 F5 进去细看——"F5 下去，几天都走不完 Spring"。
  - Debug 视图的线程栈：走深了可以一眼看清自己是怎么进来的、当前在哪个方法，还能点栈帧里的行号跳过去看。
  【原文摘录】
  #+begin_quote
  查看类很多人可能都知道，可源码阅读的时候更多用来查看方法体系更重要，可以方便快速的定位到方法的实现类。
  #+end_quote
  #+begin_quote
  个人认为这是阅读源码最有用的利器，掌握它，可以轻松游走于各种方法调用之间。然而从我身边的朋友来看，很多人都不知道他的存在。
  #+end_quote
  #+begin_quote
  断点调式时，心中必须很清楚F5、F6、F7、F8的作用，不然要么迷失于源码之中，要么什么都没看清就走完了。
  #+end_quote
  #+begin_quote
  熟悉类加载的同学会很熟悉，不熟悉类加载机制的也不要慌，这是说明你调试的类第一次被加载，这时候我们F7跳出类加载，回到40行。
  #+end_quote
  #+begin_quote
  当我们断点跟踪Spring这种源码的时候，一定要有节奏，以优先找到整体脉络为准，不要一直的F5进入每一行细看，F5下去，几天都走不完Spring。
  #+end_quote
  【我的想法】
  方法本身是 IDE 中立的：IntelliJ 里对应的是 ~Ctrl+H~（类型层级）、~Ctrl+Alt+H~（调用层级）、~Ctrl+Alt+B~（跳实现）。最值钱的是那句"以整体脉络为准"——读框架源码的正确姿势是先画调用链、再挑关键节点深入，否则很容易陷在工具类里出不来。类加载那个 F5 陷阱也很真实，能省掉一次"以为自己搞错了"的怀疑。

- 一句话概括：一个自学出身的 Linux C++ 工程师，用九个自问自答（选语言、选课、做计划、做笔记、刷 OJ、看书还是看视频）说明「学编程是学一个生态，不是学一门语言」。
【方法/论点要点】
- 科班与非科班最大的差别是："科班出身的学生知道去学什么"，知道每门课是干什么的。
- 选语言别纠结性能与难易：有方向按方向走（算法/机器学习→Python，Web→Java/PHP，底层→C）；在校生先 C 再 C++，"正是它们的难和复杂才能让你更好地理解计算机系统"，向下打通 OS/编译/网络/组成，向上能做应用；上班族时间零碎，先从 Python 入手保住兴趣，但要补《深入理解计算机系统》。
- "学习编程不是学习编程语言，而是学习一个计算机生态"——只会语言不懂体系，"就像只会写字而写不出好文章"。
- 课程：本科面向"面"、工作读研面向"点"；采用改良版项目驱动学习——学一段、做个小项目、把遇到的问题记下来、针对性补知识，同时每天抽时间完整读一本书或一个专题，把碎片串成体系。
- 爬虫案例的树形图：网络（HTTP/HTTPS、登录、GET/POST）→ HTML/DOM → 代理池 → JS 解密 → 分布式抓取与 Redis 队列 → 存储/去重/索引 → 验证码识别与深度学习。
- 计划：从 2013 年上大学起定期列计划清单，编号入表；"很难完全按照计划去执行，不过制定相应的计划能让你清楚地知道自己应该干什么"。

- 一句话概括：用 Windows 自带的"受限用户 + ACL 权限"给国产流氓软件圈一块地——建隔离账户装它、用 PowerShell 凭据以该账户身份启动它，成本比虚拟机/沙盒低。
【方法/论点要点】
- 起因：博主锁屏被百度云广告占据，追查发现是联想 OEM 后门；国内环境下又不可能完全不用某些软件，虚拟机/沙盒"大材小用"。
- 原理：ACL（Access Control List）是附在对象上的权限清单，指定哪个用户/进程能访问、能做什么；受限用户默认不能改系统文件、其他用户文件和当前用户设置，于是把毒瘤软件的行为锁在隔离账户里。
- 好处：不用切换用户或开关虚拟机；被隔离应用只能读写公共位置和隔离账户资料库；只能改隔离账户设置；仍可用剪贴板等会话级对象。
- 边界：安全性不等同于沙盒，存在 ACL 渗透提权手法，不要用它跑真正有害的软件；方法较复杂，不适合 Windows 零基础用户。
- 准备：把安装包放到"公共"位置（如 ~C:\Users\Public\Downloads~ 或其他盘根目录），要求 User 组至少有读取与执行权限。
- 建账户：~Win+R~ → ~netplwiz~ → 添加 → "不使用 Microsoft 账户登录 > 本地账户"，本例账户名 ~IsolatedApps~，并确保它只属于 ~Users~ 组。
- 装软件：不要从登录界面切过去装；在 PowerShell 里 ~$cred = Get-Credential~ 输入隔离账户凭据，再跑 ~Start-Process powershell -ArgumentList '-Command Start-Process powershell' -Credential $cred -LoadUserProfile~ 打开"窗口 2"。
- 在窗口 2 中：~$env:__COMPAT_LAYER = 'RunAsInvoker'~ → ~cd ~ 确认提示符变成 C:\Users\IsolatedApps~ → ~& '软件包路径'~ 正常安装；装不上就把安装路径改到其他盘或 Public。
- 做启动器：在窗口 2 里 ~cd ~/Desktop~ 与 ~ls~ 找快捷方式；为空则用任务管理器按用户名找进程名，再用 Everything 搜完整 exe 路径。
- 固化密码与启动脚本：~$cred.Password | ConvertFrom-SecureString | Set-Clipboard~ 取加密串，在 PowerShell ISE 里用 ~[pscredential]::new('...', ($password | ConvertTo-SecureString))~ 还原凭据，再用 ~Start-Process powershell -ArgumentList '-Command Invoke-Item ~\Desktop\...' -WorkingDirectory 'C:\' -Credential $cred -LoadUserProfile -WindowStyle Hidden~（或 ~Start-Process ...exe~）静默启动。
- 建快捷方式：目标写 ~powershell -ExecutionPolicy Unrestricted -File "C:\Users\<你>\Start-xxx.ps1"~，属性里"运行方式"选最小化，可固定到任务栏。
- 隐藏账户：新建 ~Hide-IsolatedUsers.reg~，在 ~HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon\SpecialAccounts\UserList~ 下写 ~"账户名"=dword:00000000~，导入后欢迎屏幕不再显示。
- 验证与缺陷：软件正常在隔离用户下运行；提权要管理员密码；开机自启在本用户下不生效；访问宿主文件需授权，系统文件默认只读；托盘正常但可能有小卡顿。
- 怎么选：临时偶尔用 → Win10 原生沙盒用完即走；长期装不安分的应用 → 本方法配置一次更省事；企业设备有更高权限管理员时多数提权操作做不了。

- 压缩类：JPEG 有 12 档压缩比、肉眼难辨差异但不支持 Alpha；JPEG 2000 压缩比更高、支持有损/无损与渐进式显示，因版权与 JPEG 先入为主而未流行；PCX 是 DOS 时代霸主，不支持 CMYK、上限 64K×64K，已被取代。
- 透明与动图：GIF 是动图唯一选择但只有 256 色；PNG 补上 Alpha 通道与无损压缩，颜色还原接近 JPEG，是素材与截图的首选（文中提到 macOS 窗口截图用 PNG 保留阴影）。
- 3D/特殊：JPS 与 MPO 都是左右眼双图存一文件；DICOM 是 CT/核磁/超声等医学影像专用；IFF 能同时存图像与声音，Maya 常用；PXR 是皮克斯 Typestry 的格式，软件已淘汰；TGA 能画不规则图形，也已被取代。
- 输出/印前：EPS 面向 PostScript 打印，适合出菲林，Mac 用户用得多；PDF 跨平台、支持图层与矢量、支持 RGB/CMYK/索引/LAB，但不支持 Alpha，适合存终版。
- 相机：RAW 俗称"数字底片"，保留 CMOS/CCD 原始细节给后期调色；PS 需借 Adobe Camera Raw 读取，各厂商扩展名与编码互不兼容，只能靠升级 ACR 跟进。

- 一句话概括：三步复刻 B 站那条"果冻人"短片：固定机位拍高帧率素材 → AE 里做渐变贴图并预合成 → 加 time displacement 用贴图当映射，调帧率与最大时间跨度。
【方法/论点要点】
- 三步流程：① 前期固定机位拍摄，尽量用高帧率素材；② 后期在 AE 做一张渐变贴图并预合成；③ 给视频加"时间置换（time displacement）"效果，映射图层选那张渐变合成，再调播放帧率与最大时间跨度。
- 固定机位的原因：背景像素不能变，背景里也尽量别有运动物体，否则置换会把背景一起搅乱。
- 用灰度图的原因：灰度亮度信息直观好用，但原理上任何图片都能当映射图。
- 必须预合成：时间置换只认固态图层原本的样子，你做的旋转、缩放、位置动画、遮罩它一概不认，这些必须在预合成里完成；用多个固态图层做 map 时也要先合进同一个预合成——AE 里很多效果都是这个道理。
- 置换跨度公式：~Displacement amount in seconds = maximum_displacement_time * (2 * (luminance_value – 128) / 256)~，即亮度 128 处不位移，越亮/越暗位移越大。

#+end_quote

前期固定机位是为了不让背景的像素产生变化，背景也尽量不要出现运动的物体。
#+end_quote

为什么要给固态图层预合成？因为时间置换不认！你对它做旋转缩放位置动画或者画遮罩它都只认固态图层原来的样子，这些你必须在预合成中完成。
#+end_quote

【我的想法】
文章短得像个笔记，但把最关键的"预合成"坑讲透了——这条经验可以迁移到 AE 里所有"只认原始图层"的效果（置换图、轨道遮罩、部分粒子映射）。实操上还有两点没写：渐变贴图的柔和度直接决定扭曲是否顺滑（建议加模糊），以及高帧率素材要开"时间重映射/帧混合"才不会抖动。公式里以 128 为中点，意味着贴图整体偏灰时画面几乎不动，第一次做很容易以为效果没生效。
