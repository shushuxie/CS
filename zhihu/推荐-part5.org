  - 一句话概括：直接回答「这种游戏真的存在」，主角是 Screeps——一款用 JavaScript 给单位写 AI、24 小时在持久世界里与其他玩家对抗的开源 MMO RTS 沙盘，代码强弱直接决定胜负，算力还能买卖。
  【方法/论点要点】
  - Screeps 在 Steam 上架（app 464350），官网提供免注册的 live demo 可直接试玩。
  - 官方定位：开源的 MMO RTS 沙盘游戏，核心机制是给单位编写 AI；用 JavaScript 控制殖民地，脚本 7×24 小时运行在一个持久的、充满其他玩家的世界里。
  - 实现方式很自由：可以写简单的基于规则，也可以写有限状态自动机，还可以上强化学习之类的 agent，但作者提醒性能其实很受限。
  - 游戏内容已经相当复杂：从能源、采集到防御、进攻策略，甚至还有贸易。
  - 入门门槛在英文：写代码用英文，官方文档也全是英文，需要读文档学 API（docs.screeps.com/architecture.html），文档包含系统运行逻辑、编码接口和大量内部机制，并配有 API Reference。
  - 有玩家开源了自己的代码，例如 GitHub 上的 TooAngel/screeps，可作为学习样本。
  - 收费模式是买算力（subscription token），而游戏内也能获得算力再出售，所以理论上可以靠写一个足够强的 AI 赚钱；作者建议看 Steam 页面 Attack.On.Pika[AFK] 的评论，分析得很透彻。
  - 教程第一段代码演示了最基础的采集循环：
  #+begin_src js
  module.exports.loop = function () {
      var creep = Game.creeps['Harvester1'];
      var sources = creep.room.find(FIND_SOURCES);
      if(creep.harvest(sources[0]) == ERR_NOT_IN_RANGE){
          creep.moveTo(sources[0]);
      }
  }
  #+end_src
  - 这段代码的含义：找到名为 Harvester1 的单位，找出房间内所有资源点，命令它采集第一个；若返回 ERR_NOT_IN_RANGE 说明距离太远，就让它先移动过去；整个函数会被不间断地反复执行。
  - 作者补了一句现实评价：这样只是「万里长征第一步」，得到一个会自动采集的单位，但抵御不了入侵者，也很难优化效率，想要更强的 agent 还得多烧脑。
  - 另一个发现：Screeps 的 API 支持 Binary Module，对性能要求高的部分可以写 C 代码编译成二进制库，再在 JavaScript 里调用。

  【我的想法】
  这个回答真正有意思的点不是「有这款游戏」，而是它揭示了一个设计难题：一旦允许程序代打，胜负就退化成算力与工程能力的比拼，普通玩家的操作乐趣被挤出。Screeps 用「买算力 + 英文文档 + 性能受限」把门槛抬得足够高，才勉强维持平衡；这恰好解释了为什么大多数网游宁可封挂也不开放接口。

  - Codrops（tympanus.net/codrops）：发表技术文章和网页教程、提供经验，很多优秀技术出自这里。

  - CodePen（codepen.io）：前端设计开发平台，汇集各种效果案例与炫技 demo，可在其基础上开发自己的设计。
  - Neumorphism（neumorphism.io）：新拟态效果生成器，可改颜色、尺寸、半径、距离、强度、模糊、形状，直接复制 CSS 代码。
  - uiGradients（uigradients.com）：提供接近上百种渐变配色方案，可挑选并直接拿到对应 CSS 代码。
  - HTML5 UP（html5up.net）：大量 HTML5 免费模板，可自行分享和修改。
  - ICONSVG（iconsvg.xyz）：在线自定义设计 SVG 图标，都是常用图标，可二次设计并导出。
  - OpenMoji（openmoji.org）：提供源代码、可免费下载使用的表情符号库。
  - Share Icon（shareicon.net）：超过 25 万个 ICON 矢量素材，120 多种分类，提供 PNG/SVG、多种尺寸（512 到 16），适合收藏备用。

  【方法/论点要点】
  - 鸟哥的书正面三点：至今蝉联最受欢迎华语 Linux 书籍第一；作者本人从零基础自学，所以循序渐进；非常口语化，比堆术语的技术书好接受。
  - 反面两点：太厚且大而全，入门者不知道哪些是重点、从何入手；有部分内容和废话略显啰嗦。
  - 核心判断：书好不好取决于需求。初学者不建议看，因为太厚、啥都有，看到后面忘前面，读完整本容易「啥都懂，但啥也都不懂」；有一定基础后这本书非常适合，是进阶必备。买之前可先去鸟哥官网看在线版。
  - 入门书籍通常覆盖的内容：Linux 历史、文件与目录管理、文本处理、磁盘管理、进程管理、性能监控、网络工具、用户管理、系统管理、Shell 编程。
  - 入门书单：
    1. Linux Tools Quick Tutorial——小而美的电子书，几天能看完，先建立初步印象，作者明确说不想一上来就推砖头书。
    2. 《Linux 从入门到精通》——作者原本鄙视「XX 天精通」流派，翻过后发现内容相当不同，觉得书名反而拖累它；覆盖上述各方面还讲服务器基础，附 12.5 小时教学视频、Ubuntu 安装镜像和 31.5 小时专题视频。
    3. 《鸟哥的 Linux 私房菜》——定位为老司机进阶书，不适合入门第一本。
    4. 《Linux 就该这么学》——不厚、重点突出、覆盖绝大部分重点知识，官网可在线免费看，与红帽 RHCE 认证相关。
    5. 《Linux 命令行与 shell 脚本编程大全》——面向整天在命令行工作的人，四部分：Linux 命令行、shell 脚本编程基础、高级 shell 脚本编程、如何创建实用的 shell 脚本。
    6. 《Linux Shell 脚本攻略》——很薄，没有长篇大论，由许多小技巧组成。
    7. 《Linux 命令行大全》——作者没看过，转述网友评价：为初学者量身定做，结构循序渐进，重点难点反复出现，零经验也能跟着走。

  - 一句话概括：一个长期用 iPad + 罗技 K380 的用户，从选购理由、价格渠道写到三设备切换、app 快捷键、截屏分屏的具体按键，是少见的把「键盘怎么用」而不是「键盘参数」讲清楚的体验帖。
  【方法/论点要点】
  - 选 K380 而不是 K480：K380 是 K480 的升级版，去掉了撑架所以更小巧好看，价格淘宝 160–200，京东 248，作者在苏宁下单更便宜。
  - 明确不符合题主前两条要求：单键盘不带支架、不能和 iPad 合体；但满足打字手感和便携。
  - 动机很具体：iOS 9 之后有分屏，横屏一边微信一边豆瓣时虚拟键盘占掉大半屏幕；写备忘录时键盘升起降下、内容被顶到最上面还要往回拉，很烦。
  - 尺寸对照：iPad Air 2 是 240 × 169.5 × 6.1，K380 是 279 × 124 × 16，宽度接近笔记本键盘，所以打字不憋屈。
  - 三设备切换：F1–F3 分别对应三个蓝牙设备；F4 是 Home，F6 开关虚拟键盘，F7 返回，F8/F9/F10 是上一首/下一首/暂停，F11/F12 及其后一个键控音量。
  - 截屏是 fn + tab，看视频截画面很方便。
  - 默认是数字键选词，改成空格键确认选词之后打字速度明显提升；设置在「设置 → 键盘」里。
  - 长按 alt（即 cmd）会弹出当前 app 的快捷键列表，QQ 等应用都支持；iThoughts 里 tab 建子主题、回车建同级主题、按数字键决定展开层级。
  - 支架是关键配件：早先八九十块的淘宝支架塑料球头会脆断，后来换成全金属一体式，小米有品约 50 多，大号支持 12 寸以下平板、小号 7 寸以下，11 寸 iPad Pro 用大号刚好。
  - 换成 iPad Pro 11 寸后仍用 K380，没买苹果原装键盘的三个理由：已有 K380；体验店里觉得原装键盘太薄、打字不舒服；自己有独立支架，比「键盘+支架+保护套」三合一更舒服。
  - iPad Pro 的截屏改成 macOS 逻辑：shift+command+3 直接存全屏，shift+command+4 进编辑界面可以画圈标注。
  - 分屏有四种形态：大中分、屏上漂浮、左大右小、左小右大，作者认为分屏挽救了 11 寸非原生应用的丑空边。
