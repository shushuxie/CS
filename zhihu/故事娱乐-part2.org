  - 一句话概括：两个“好字被姓毁掉”的取名段子——风平浪静四姐妹偏偏姓巨，珍珠翡翠四姐妹偏偏姓赵，笑点在雅致名字和姓氏连读后的翻车，以及当事人拼命反抗的那个。
  【方法/论点要点】
  - 第一个例子：高中男同学有四个姐姐，单名依次是风、平、浪、静，单看极为好听，可一家姓巨，连起来全变味；老五就是作者同学，叫巨文。
  - 作者的同情点：“我感觉最亏的是他三姐”，因为“巨浪”最惨。
  - 第二个例子：老家远方嫂子有四个姑娘，经高人指点改成单名珍、珠、翡、翠，可全家姓赵，“赵珍、赵珠、赵翡、赵翠”同样翻车。
  - 结局的反差：二姑娘死活不同意、拼命闹，最后老大老三老四改了，只有老二保住原名——全家唯一清醒的人。

  #+end_quote

* Fabrice Bellard 是个什么水平的程序员？  :故事娱乐:程序员:开源:人物:
  :PROPERTIES:
  :链接:  https://www.zhihu.com/question/28388113/answer/1920246970066375044
  :作者:  奉贤一理工直男
  :原文:  [[file:原文/2026-10-19-FabriceBellard是个什么水平的程序员-1920246970066375044.org][本地原文]]
  :抓取:  2026-10-19
  :END:
  - 本地原文：[[file:原文/2026-10-19-FabriceBellard是个什么水平的程序员-1920246970066375044.org][打开本地归档]]
  - 一句话概括：转自公众号"码农翻身"的一篇人物小传，用一条从 LZEXE 到 QuickJS 的时间线说明法国程序员 Fabrice Bellard 的跨度——操作系统、模拟器、多媒体、图形学、编译器、编程语言、通信、数学轮流玩一遍，且"写出来的程序还总是比别的程序小几个数量级，快几个数量级"；值得收是因为它把"技术广度和深度能同时到什么程度"这件事用一个具体人物钉住了。
  【方法/论点要点】
  - 总评：作者认为若单论技术能力，有一个人也许比 Linus Torvalds（Linux 与 Git 的作者）更强——"这家伙一定是穿越回来的"；理由是"他写的程序还总是比别的程序小几个数量级，快几个数量级"。
  - 作品跨度：著名模拟器 QEMU、音视频处理库 FFmpeg、C 编译器、OpenGL 实现、LTE 软基站、JS 引擎，让 Linux 在浏览器中跑起来，甚至创造过计算圆周率的世界纪录。
  - 17 岁（高中）：因硬盘又小又贵，用汇编语言写了压缩程序 LZEXE；压缩效果极好，被朋友 Copy 并放到 BBS，"成了 DOS 时代最火的压缩工具之一"。
  - 1996 年（24 岁）：写了一个 Java 虚拟机，可以把 Java 代码编译成 C 代码执行。
  - 1997 年：改良 Bailey–Borwein–Plouffe 公式，提出当时最快速的计算圆周率算法，大幅降低时间复杂度；新算法被命名为 Bellard 公式，"从此他在数学社区建立了自己的声望"。
  - 1998 年：做虚拟现实引擎时需要 OpenGL，觉得开源实现 Mesa 太慢，于是自己写了 TinyGL——实现 OpenGL 子集，比 Mesa 和商用实现快得多、占用资源少得多，"并且比任何一个都小几个数量级"。
  - 2000 年：化名 Gérard Lantau 开始 FFmpeg，这是他最重要、最广为认可的项目之一；FFmpeg 是数字音频视频的"瑞士军刀"，VLC、YouTube、iTunes 都依赖它。
  - 2000、2001 年：连续两次在 IOCCC（国际 C 语言代码混淆竞赛）获奖——2000 年的获奖作品用快速傅里叶变换在较短时间内计算出已知最大素数（2^6972593-1）。
  - 2001 年（比赛副产品）：TinyCC，世界上最快、最小的 C 语言编译器；为证明其威力，基于它做的 TCCBoot 只有 138K，能在 15 秒以内编译完 Linux 内核并启动。
  - 2005 年：发布 QEMU，用软件模拟 CPU、内存、I/O 设备，给操作系统营造运行在硬件上的假象；难度"甚至比操作系统都高"。
  - 2009 年：用一台不到 2000 欧元的桌面 PC（2.93GHz Core i7、6GB 内存、7.5TB 硬盘）算出圆周率小数点后 2.7 万亿位，打破由世界第 47 名的 T2K Open 超级计算机保持的纪录——"一个人加一台电脑，竟然击败了超级计算机"。
  - 2011 年：JSLinux——用 JavaScript 写了一个 PC 模拟器，让 Linux、Windows 能在浏览器里跑；仿真 32 位 x86 兼容处理器、8259 可编程中断控制器、8254 可编程中断计时器、16450 UART，既支持命令行也支持图形界面，Windows 2000 都能跑起来。
  - 2012 年：一个人花 10 个月、在一台 i7 四核 PC 上实现了运行效率极高的 LTE 软基站，支持 LTE TDD/FDD、NB-IoT、eMTC，最大可支持 5 载波 2x2 MIMO 或 3 载波 4x4 MIMO。
  - 2019 年：发布嵌入式 JavaScript 引擎 QuickJS，支持 ES2020，只有几个 C 文件、无任何外部依赖；单核 CPU 上 95 秒内完成 69000 个 ECMAScript 测试。
  - 总体印象："他可以轻易进入一个他觉得有趣的领域，成为这个领域的专家，留下一个让其他人愿意花费数年时间维护的软件，自己则轻飘飘地离开，进入下一个领域。"
  - 关于动机：被问为何研究这么多不同东西时，他说"我讨厌一直做同样的事情，所以一定要切换不同的项目来玩"；作者点评这与 Linus 的 Just for fun 一脉相承。
  - 为人：对金钱或名声不感兴趣（用化名做开源项目即为证明），极少接受媒体采访，网上资料很少，"远不如 Linus 那样声名远扬"；主页是 ~http://bellard.org~。
