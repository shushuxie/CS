* 文字流的魅力
    EMACS说白了主要是文字记录，最主要的缺点在于没法插入图片，导致一些图表没法插入进来
但是文字流也有好处，就是对于逻辑的，文字的描述要求更加严格；
    想要用的好还需要好好的进行练习，形成一种习惯就是不去思考快捷键然后自然的使用，像我
现在的使用很多的操作还要进行思考，然后就打断了思考，最后感觉处处受阻。可有增加一些快捷键
的习惯练习。
  
* 常用的操作方式

1. todo添加
   * *,at* 查看todo等方式
   * *,ag* git操作
     * F fetch拉取
     * P push
2. org特殊格式
   * **text** 加粗
   * *~text~*  ~text~
   * *_text_* _下划线_
3. 其他快捷方式
   * *,<* 插入模板，latex，src等
   * *,|* table
4. 文件搜索
   新建文件treemacs
   新建目录treemacs
   搜索文件 projectial *,pf ,pd ,pg ,pr*
   pd是搜索文件夹，可以打开文件夹视图进行文件跳转
